Questions from the craft table

Do I need to know CSS to use Paperfold?expand_more

No. Palettes, torn edges, and shadows are driven by tokens you set once in a visual editor. Editing the CSS variables directly is always available if you want finer control.

Does dark mode really come built in?expand_more

Yes. Every palette ships with a matched dark set using deep warm browns and cream text, checked for WCAG AA contrast in both directions. The toggle persists across visits.

Can I export my pages?expand_more

Studio and Bindery plans export a single self-contained HTML file with all styles and scripts inline, ready to host anywhere with no build step.
