Common questions

Yes. The component library is open source under the MIT license. Paid plans only add support services, never locked components.

Dark mode ships as a first-class theme. Swap the theme object at the provider level and every component updates, including focus rings and borders.

Every component accepts an overrides API that targets its internal parts. You restyle slots directly instead of fighting specificity or forking source.

Base Web targets React. It works with any bundler and supports server-side rendering out of the box.

Components ship with keyboard interaction tests, screen reader audits, and automated contrast checks that run on every pull request.
