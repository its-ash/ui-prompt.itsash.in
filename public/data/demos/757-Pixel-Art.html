Frequently Asked Questions

What platforms can I export to?
Pixel Forge exports to standard NES ROM format (.nes) and HTML5 for web play. ROMs work on emulators and flash carts like EverDrive.
Do I need to know how to code?
Absolutely not! Our visual scripting system lets you build game logic by connecting nodes. Advanced users can still inject custom assembly if needed.
Is there a limit to game size?
Free tier limits projects to 16KB ROM size. Pro and Studio tiers support up to 512KB with mapper support (MMC1, MMC3, etc.).
Can I use my own assets?
Yes! Import PNG spritesheets, MIDI files, and custom palettes. We automatically convert them to NES-compatible formats during import.
How does cloud saving work?
Your projects are saved to our secure servers with automatic version history. Enable sync in settings to access work from any device.
