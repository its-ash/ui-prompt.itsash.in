AI agents, written in TypeScript.

VoltAgent is an open-source framework for building, observing, and shipping production agents with the tools you already know.

$ npm install @voltagent/core
Read the docs
agent.ts 
import { Agent, createTool } from '@voltagent/core';

const weather = createTool({
  name: 'weather',
  execute: async ({ city }) => getWeather(city),
});

// Traced, typed, ready to deploy
export const assistant = new Agent({
  name: 'assistant',
  tools: [weather],
});

Built for engineers, not demos

Everything you need to take an agent from a local script to a monitored production system.

verified

Type-safe agent APIs

Agents, tools, and memory are fully typed end to end. Catch schema mismatches at compile time, not in production logs.

memory

Tools and memory built in

Register tools with one function call and give agents persistent memory across sessions with pluggable storage adapters.

monitoring

Observability and tracing

Every LLM call, tool execution, and retry is traced automatically. Inspect full agent runs in the built-in console.

Three steps to a running agent

No YAML pipelines, no hosted lock-in. Just a package, a few lines of code, and a deploy target.

01

Install

Add the core package with npm install @voltagent/core. Works with Node 18+, Bun, and Deno.

02

Define

Declare your agent with new Agent(), attach tools and memory, and pick any supported model provider.

03

Deploy

Ship to any Node runtime or serverless platform. Traces stream to the console from the first request.
