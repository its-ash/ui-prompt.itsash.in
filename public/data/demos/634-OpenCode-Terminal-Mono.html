# features

Built for people who already live in a shell.

keyboard

Keyboard-first TUI

A fast terminal interface with vim-style navigation, fuzzy file pickers, and zero mouse dependency.

opencode --vim
hub

Bring your own model

Point opencode at Anthropic, OpenAI, Google, or a local model over Ollama. Swap providers per session.

opencode --provider ollama
lock

Local-first privacy

Your code stays on your machine. Only the prompts you approve leave, over your own API keys.

opencode --offline

# how it works

Three commands from install to first shipped patch.

  1. 01

    $ install

    One npm package, no daemon, no account. Works on macOS, Linux, and Windows via WSL.

  2. 02

    $ connect

    Drop in an API key or point at a local model. opencode detects your repo, toolchain, and test runner.

  3. 03

    $ ship

    Describe the change in plain English. Review the diff, run the tests, commit when you are happy.

# faq

What do I need to install opencode?expand_more

Node.js 18 or later and a terminal. Install with one npm command; there are no daemons, accounts, or background services.

Which models and providers are supported?expand_more

Anthropic, OpenAI, Google, Mistral, and any OpenAI-compatible endpoint, including local models through Ollama or llama.cpp. You can switch providers mid-session.

Does my code leave my machine?expand_more

Only the context included in a prompt you approve is sent to your chosen provider. With a local model and the offline flag, nothing leaves your machine at all.

What license is opencode released under?expand_more

MIT. You can use, modify, and redistribute it freely, including in commercial products.

Can I self-host the Pro features?expand_more

Yes. The Team tier includes a self-hosted relay for model routing, audit logs, and SSO, deployable as a single container.

What is actually free?expand_more

The entire agent: TUI, tools, providers, and offline mode. Paid tiers only add hosted models, sync, and team administration.
