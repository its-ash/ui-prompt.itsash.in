# faq

What are the system requirements? expand_more
opencode runs on macOS 12+, Linux (Ubuntu 20.04+, Fedora 36+), and Windows 10/11 via WSL2. Requires Node.js 18+ or Rust toolchain for binary installation.
Which models and providers are supported? expand_more
Any OpenAI-compatible API (OpenAI, Anthropic, Azure, local Ollama, Llama.cpp). Configure via environment variables or config file.
Is my code and data private? expand_more
Yes. In local mode, all processing stays on your machine. With cloud models, only prompts and context are sent to your chosen provider—we never store your code.
What license is opencode released under? expand_more
MIT License. See GitHub for details.
Can I contribute or self-host? expand_more
Absolutely. opencode is open-source. Contribute via GitHub or self-host the registry for air-gapped environments.
