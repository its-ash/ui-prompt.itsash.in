How it works

Three steps between you and a shipped project. We counted.

1

Dump the tasks

Type everything that needs doing onto the board. Messy is fine. Order comes later.

2

Assign and date

Give each task one owner and one deadline. Two fields. That is the whole form.

3

Mark it done

Drag finished work to the done column. Watch the board empty. Repeat weekly.
