What is Nimbus?
Nimbus is a cloud-based Amiga Workbench emulator that lets you experience the classic Commodore Amiga environment from any modern browser.
Do I need to install anything?
No installation required. Nimbus runs entirely in your web browser using WebAssembly technology for authentic 68000 CPU emulation.
Can I save my work?
Yes! Your virtual hard drive persists between sessions, and you can export files to your local machine at any time.
