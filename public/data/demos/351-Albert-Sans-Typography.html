FAQ

Questions,
answered.

Do I need to own font licenses?expand_more

No. Nimbus ships with a curated library of open-license faces like Albert Sans, and it connects to any licensed webfonts your team already owns.

Can Nimbus export to our design system?expand_more

Yes. Export to CSS variables, SCSS maps, JSON tokens or design-lib plugins. Every export is versioned, so changes diff cleanly in review.

How does the contrast audit work?expand_more

Every type pairing is tested against WCAG 2.1 AA and AAA thresholds in both light and dark themes — before a single line reaches production.
