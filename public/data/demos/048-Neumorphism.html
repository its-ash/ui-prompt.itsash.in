FAQ

Common questions

Do the shadows stay visible in dark mode?expand_more

Yes. Dark themes swap in a deeper outer shadow with a faint light inner highlight, so embossed surfaces never flatten after sunset.

Is the pastel palette accessible?expand_more

Every surface pairs with a pre-audited text token that clears WCAG AA in both light and dark themes — contrast is never left to guesswork.

Does Nimbus work with my existing framework?expand_more

Tokens are plain CSS variables, so they drop into Tailwind configs, CSS-in-JS setups, or plain stylesheets without any build step.
