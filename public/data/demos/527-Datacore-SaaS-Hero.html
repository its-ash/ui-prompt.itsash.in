Frequently asked questions

Answers to common questions about Datacore

How does Datacore ensure data consistency across regions?

expand_more

Datacore uses conflict-free replicated data types (CRDTs) and vector clocks to achieve eventual consistency with configurable consistency levels per namespace.

What compliance certifications do you have?

expand_more

We are SOC 2 Type II, ISO 27001, HIPAA, and GDPR compliant. Additional certifications like PCI DSS are available for enterprise plans.

Can I use my own encryption keys?

expand_more

Yes, Datacore supports customer-managed encryption keys (CMEK) via AWS KMS, Google Cloud KMS, or Azure Key Vault for data at rest.

How do you handle data residency requirements?

expand_more

Data never leaves selected regions unless explicitly configured. You can enforce residency policies at the namespace level with audit logging.
