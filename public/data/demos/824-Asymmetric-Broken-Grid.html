04

FAQ

01 Is OFFSET suitable for beginners?

Absolutely. While OFFSET embraces advanced layout techniques, the interface is intuitive and includes guided tutorials to help beginners master asymmetric design principles quickly.

02 Can I export my layouts for web development?

Yes. OFFSET exports clean HTML/CSS with precise positioning values, making handoff to developers seamless. You can also export as PNG, SVG, or PDF for static use.

03 Does OFFSET work with design systems?

Definitely. Create and share custom components, styles, and constraints within your team to maintain consistency while still enjoying layout freedom.

04 Is there a mobile app?

Currently, OFFSET is a web-based desktop application optimized for modern browsers. We prioritize the precision and screen real estate needed for professional layout work.

05 How does the hard shadow effect work?

Unlike traditional blurred shadows, OFFSET uses solid 4px, 8px, or 14px offsets with zero blur to create sharp, dimensional depth that enhances the asymmetric tension.

06 Can I collaborate with my team in real-time?

Real-time collaboration is available in the Studio and Team tiers, featuring presence indicators, comment threads, and version history for seamless teamwork.
