Frequently Asked Questions

Do I need coding experience to use Nimbus?

expand_more

Not at all! Nimbus uses a visual scripting system for game logic. Advanced users can access JavaScript APIs, but beginners can create fully interactive worlds without writing a single line of code.

Can I sell or monetize worlds I create?

expand_more

Absolutely! You retain full rights to your creations. Sell them on marketplaces, use them in commercial projects, or monetize through ads and in-app purchases.

What file formats can I export to?

expand_more

Export as HTML5 web apps, Android/iOS apps, Windows/Mac/Linux executables, or as standard voxel formats like .vox and .magica for use in other tools.
