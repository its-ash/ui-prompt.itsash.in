FAQ

Questions, answered

Do viewers need an account to use a demo?expand_more

No. Published demos open instantly in any modern browser — no signup, no plugin, no download. You can optionally gate a demo behind an email form to capture leads.

How is this different from a recorded video?expand_more

Videos are passive. Flowboard demos are clickable: prospects interact with your real UI flows, and every click, hover, and drop-off is tracked so you learn what actually interests them.

Can I edit a demo after it's published?expand_more

Yes. Edit steps, copy, and hotspots any time — changes go live instantly everywhere the demo is embedded. No re-recording, no version chaos.

Does Flowboard work with my tech stack?expand_more

Demos embed anywhere HTML lives — React, Vue, Angular, WordPress, docs portals, or plain HTML — with a single script snippet. No SDK required.

How is my data handled?expand_more

We're SOC 2 Type II certified, offer EU or US data residency, and are fully GDPR compliant. Enterprise plans add SSO, audit logs, and custom retention policies.
