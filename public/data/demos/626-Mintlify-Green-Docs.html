Features

Everything a docs site needs, built in

Search, API references, and components work out of the box, so your team writes content instead of maintaining tooling.

search Search

Instant search

Full-text search indexes every page on each deploy. Results rank by heading, body, and code blocks in under 50ms.

api OpenAPI

Auto-generated API reference

Point Nimbus at your OpenAPI spec and get interactive endpoint pages with try-it consoles, kept in sync on every commit.

widgets MDX

MDX-powered components

Drop callouts, tabs, cards, and code groups into any page. Write your own React components when the defaults are not enough.

Live in three steps

From an empty folder to a published docs site in about five minutes.

01

Write in MDX

Create pages as plain MDX files in your repo. Frontmatter controls titles, descriptions, and navigation order.

pages/quickstart.mdx
02

Connect your repo

Link GitHub or GitLab once. Nimbus builds a preview for every pull request so reviewers see rendered changes.

nimbus link
03

Merge to publish

Merging to main deploys to a global CDN with analytics, versioning, and custom domains already configured.

git push origin main

Frequently asked questions

Do I need to know React to use Nimbus?expand_more
No. Pages are plain MDX with optional components. React knowledge only helps if you want to build custom components beyond the included library.
Can I migrate from an existing docs platform?expand_more
Yes. The CLI imports Markdown and MDX folders, preserves your navigation structure, and flags broken internal links before your first deploy.
What happens when I cancel a paid plan?expand_more
Your site stays live on the Starter plan. Custom domains and versioning are disabled, but all content and history remain in your repository.
