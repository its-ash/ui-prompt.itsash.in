Frequently asked questions

Straight answers for teams evaluating an infrastructure platform.

Can Nimbus manage existing infrastructure?expand_more
Yes. Import tools read your current cloud accounts and generate configuration and state for existing resources, so adoption does not require rebuilding anything.
How does the secrets engine handle rotation?expand_more
Credentials are issued on demand with short leases and revoked automatically on expiry. Applications fetch secrets at runtime, so rotation requires no redeploys or config changes.
What compliance certifications do you hold?expand_more
Nimbus Cloud is SOC 2 Type II and ISO 27001 certified. Enterprise plans add support for HIPAA workloads and customer-managed encryption keys.
