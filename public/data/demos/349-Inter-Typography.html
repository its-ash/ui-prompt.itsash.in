Inter — the interface typeface

Designed for the screen.

Inter is a free, open-source typeface family built for user interfaces, dashboards, and the contemporary web — 28 styles, weights 100 through 900, one variable file.

FAQ

Questions, answered.

Is Inter really free? expand_more

Yes. Inter is released under the SIL Open Font License 1.1, so it’s free for any use — personal, commercial, and embedded.

Can I use Inter in a commercial product? expand_more

Yes. Ship it in apps, sites, and products. The license only forbids selling the font files by themselves.

What’s included in the download? expand_more

All 28 static styles plus one variable font, in WOFF2, WOFF, and OTF formats.

Does Inter support variable fonts? expand_more

Yes — a single variable file interpolates the full weight range from 100 to 900.

Which languages does Inter cover? expand_more

Latin, Cyrillic, and Greek scripts across 2,000+ glyphs, with coverage growing every release.

How do I self-host the webfonts? expand_more

Add an @font-face rule pointing at the WOFF2 files, or install the package from npm.
