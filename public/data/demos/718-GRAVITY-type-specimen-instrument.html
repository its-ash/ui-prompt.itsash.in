05 — FAQ

Frequently asked questions

What file formats are supported? add

TTF, OTF, and WOFF2 variable or static fonts. The library also includes a curated set of open‑source faces.

Can I adjust optical size? add

Yes. The optical size axis (opsz) is exposed alongside weight and width for precise rendering at any point size.

Are exports royalty‑free? add

Exported proofs are royalty‑free for personal and commercial use. Font licensing follows the original provider’s terms.
