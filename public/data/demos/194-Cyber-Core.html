FAQ TRANSMISSION

Is Cyber Core compatible with legacy systems?expand_more

Yes — the core node exposes a POSIX-compatible bridge and speaks raw TCP, so even mainframe-era services join the mesh.

What happens if a core node goes offline?expand_more

The mesh is self-healing: nodes buffer locally and re-sync automatically. No data loss, no manual recovery.

Can I self-host Cyber Core?expand_more

Operator tier and above ship a full air-gapped kit with signed images and offline update bundles.
