Details

Precise answers.

How strict is the grid?expand_more

The base unit is fixed at 60 points, with 30- and 15-point subdivisions for dense layouts. Off-grid placement is flagged and measured, never silently accepted.

Can I import existing files?expand_more

Yes. Nimbus reads Figma and Sketch files, maps each layer to the nearest grid line, and reports every adjustment it makes.

Do team libraries sync?expand_more

Studio and Atelier plans include shared token files and component libraries, synced across every project in real time.
