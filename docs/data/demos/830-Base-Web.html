Frequently Asked Questions

What is Base Web?

Base Web is a set of low-level primitives that help teams build consistent, accessible UI components.

How do I start?

Clone the repo, install dependencies, and import the primitives you need.

Is it open source?

Yes, it is released under the MIT license.

Can I customize colors?

Yes, override the CSS variables to match your brand.

How is accessibility handled?

All primitives include ARIA attributes and keyboard focus styles.
