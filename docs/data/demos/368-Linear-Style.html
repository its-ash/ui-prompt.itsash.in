Frequently asked questions

Everything else you’re probably wondering.

How does Vela connect to my stack?expand_more
Vela connects read-only to GitHub, GitLab, and Bitbucket via OAuth, and ingests metrics from Datadog, Grafana, or any Prometheus endpoint. Setup takes under ten minutes, and you can revoke access at any time.
Does Vela store our source code?expand_more
No. Vela reads repository metadata — commits, touched files, and ownership — but never clones or stores your code. All metadata is encrypted at rest and deleted within 30 days if you disconnect.
Can we self-host Vela?expand_more
Yes. Enterprise plans include a single-tenant install that runs in your own VPC on Kubernetes, with the same feature set as the cloud offering and no data ever leaving your network.
