FAQ

Frequently asked questions

Does Nimbus train on our data?

expand_more

No. All queries run read-only against your warehouse, and nothing is retained after a response is delivered. Models are never fine-tuned on customer data.

Which data sources are supported?

expand_more

PostgreSQL, Snowflake, BigQuery, Redshift, Databricks and S3, plus 40+ managed connectors. New sources ship monthly.

Do teammates need SQL to use it?

expand_more

No. Questions are asked in plain language and answered in seconds. Every answer ships with the generated SQL and source rows, so technical reviewers can verify any result.
