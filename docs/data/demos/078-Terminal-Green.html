get started
[ v2.0 — public beta ]

Ship production from your terminal.

nimbus is a CLI-first deploy tool. Declare your stack once in nimbus.toml, push, and ship — rollbacks, preview environments, and logs are one flag away. No dashboard required.

get startedarrow_forward
$ npm i -g nimbus
~/acme-app — zsh
$ nimbus login
✓ authenticated as @dev — token cached in keychain
$ nimbus deploy --prod
▸ building   → done in 6.2s (cache HIT)
▸ uploading  → 142 files · 4.1 MB
✓ live at https://acme.nimbus.app # 42s, zero config touched
$ nimbus logs --tail
$ ls ./features

Everything a dashboard does — minus the dashboard.

bolt

Zero-config builds

nimbus detects your stack, builds in isolated containers, and caches every layer. Median cold build: 40s.

nimbus build --prod
lock

Secrets stay local

Tokens live in your OS keychain and are injected at build time. They never appear in CI logs or leave your machine unencrypted.

nimbus secrets audit
terminal

Instant rollbacks

Every deploy is immutable and addressable. Return to any point in history faster than your pager goes off.

nimbus rollback @2
$ run --steps

keyConnect

Log in once. nimbus links your repo, registry, and DNS, and writes it all to a nimbus.toml you can read in one sitting.

nimbus login

rocket_launchShip

Every push triggers a deploy with health checks baked in. Failures roll back before you finish reading the output.
