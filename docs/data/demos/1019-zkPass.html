Features

Private by design, fast by default

Three primitives cover most verification flows. Compose them into full user journeys without touching raw data.

PRIMITIVE / 01

Proof issuance

Turn a credential into a signed proof in one call. No storage, no data movement, no extra infrastructure.

proof = issue(credential, policy)
verify(proof) -> true
status: ready
PRIMITIVE / 02

Policy engine

Define who can prove what, when, and to whom. Policies live in code and version with your app.

policy = { age: ">=18", region: "EU" }
enforce(proof, policy)
status: active
PRIMITIVE / 03

Audit trail

Every proof leaves a tamper-evident record. Review activity without exposing user payloads.

log = audit(proofId)
export(log, format="json")
status: logged
How it works

Three steps from credential to proof

STEP 01

Connect a source

Point Cipherline at the credential issuer or wallet your users already trust. No migration required.

source.connect()
STEP 02

Define the policy

Write the rule in plain code. Cipherline checks the proof against it at verification time.

policy.define()
STEP 03

Share the proof

Users present a proof, not their data. Verifiers get a yes or no, nothing more.

proof.share()
