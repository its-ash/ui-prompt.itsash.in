man nimbus // faq

whoami — is it really one binary?expand_more

Yes. 9MB, statically linked, zero runtime dependencies. If it fits on a floppy's ghost, it ships.

where do my secrets live?expand_more

In an AES-256 vault compiled into the core. Secrets are injected into memory at deploy time — never written to disk, never printed to logs.

does nimbus run air-gapped?expand_more

Fully. Host the mirrors on bare metal inside your perimeter; the binary never phones home.

can i self-host the control plane?expand_more

On MAINFRAME, yes: "nimbus relay init" and the whole plane is yours, audit trail included.

what happens when something breaks?expand_more

Run "nimbus revert" — the last signed snapshot is restored in ~300ms. Then "nimbus doctor" names the exact layer that lied.
