FAQ

Answers to common questions about color science and accessibility.

We support RGB, sRGB, Display P3, LAB, LCH, HCL, and CMYK. All conversions use ICC v4 profiles with perceptual intent preservation for accurate cross-device matching.

Every mix is evaluated against WCAG 2.1 using the luminance contrast ratio formula. We test both normal and large text thresholds at AA and AAA levels, reporting pass/fail states with exact ratio values.

Export as ASE (Adobe Swatch Exchange), JSON, CSS variables, SVG gradients, Figma plugins, iOS UIColor/Android ColorStateList, and Adobe Color themes. All exports include contrast metadata.

CHROMA LAB works in all modern browsers: Chrome, Firefox, Safari, and Edge. We use progressive enhancement — core functionality works without JavaScript, while advanced features like the mixer visual enhance the experience.
