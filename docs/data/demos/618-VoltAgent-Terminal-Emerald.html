Build AI agents terminal first

Type-safe agent APIs with built-in tools, memory, and observability. Deploy anywhere with zero config.

assistant.ts
import { Agent, createTool } from '@voltagent/core';
const weather = createTool({
name: 'weather',
execute: async ({ city }) => await getWeather(city),
});
export const assistant = new Agent({
name: 'assistant',
tools: [weather],
});

Features

lock

Type-Safe by Design

Full TypeScript support with compile-time safety for agent inputs, outputs, and tool schemas. Catch errors before runtime.

memory

Built-in Tools & Memory

Pre-built tools for web search, file operations, and APIs. Persistent memory with vector storage for context retention.

monitoring

Observability & Tracing

Real-time tracing, token usage tracking, and error debugging. Export traces to Jaeger or view in the dashboard.

How It Works

01

Install

Add VoltAgent to your project with a single command. Zero dependencies, peer-only.

npm i @voltagent/core
02

Define

Create tools and agents using intuitive TypeScript APIs. Leverage built-in tools or bring your own.

const agent = new Agent({ tools: [webSearch] });
03

Deploy

Run anywhere: Node.js, Deno, browsers, or edge platforms. Docker-ready with health checks.

agent.run({ input: "What's the weather?" });
