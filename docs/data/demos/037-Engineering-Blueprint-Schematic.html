SEC. 03 // How it works

Bare metal to live data in three operations.

  1. 01

    hubConnect

    Point STRATA at your historians, brokers and device fleets. Autodiscovery maps every tag, unit and sample rate — no hand-written collector configs.

  2. 02

    straightenCalibrate

    Import tolerances and SPC limits from revision-controlled spec sheets, then set alert thresholds once. They follow the data everywhere.

  3. 03

    speedOperate

    Watch telemetry stream live while alerts, rollups and scheduled exports run themselves. You review exceptions, not log files.
