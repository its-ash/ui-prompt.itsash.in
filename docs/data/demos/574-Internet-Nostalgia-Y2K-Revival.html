Frequently Asked Questions

Everything else you might want to know before dialing in.

Do I need to know HTML to build my page? add remove
Not at all. The builder is fully visual: drag windows, badges and counters where you want them. If you do know HTML, an advanced mode lets you edit the source like it is 1997.
Will my page work on modern phones? add remove
Yes. Every page looks authentically retro but is built on modern, responsive code. It renders beautifully at 800x600 and on any phone screen, with no horizontal scrolling.
Can I move my existing GeoCities-era page over? add remove
Absolutely. Paste your old HTML into the import tool and we preserve your layout, images and guestbook entries, then wrap it in fresh beveled chrome. Your webring neighbors will never know the difference.
