Frequently Asked Questions

chevron_right How does the clay rendering work?
Our engine converts meshes into soft clay simulations using a physically‑based shader that respects matte finishes and gentle top‑lighting.
chevron_right Can I use Nimbus offline?
Yes. The core modeling engine runs locally; only the asset library requires an internet connection.
chevron_right What file formats are supported?
OBJ, FBX, glTF, and our native .nclay format for preserving clay properties.
