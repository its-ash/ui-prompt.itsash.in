FAQ

How is WPM calculated? expand_more
WPM = (correct keystrokes / 5) / (time in minutes). We subtract a penalty for each error to reflect net speed.
Can I use any keyboard layout? expand_more
Yes. The game measures raw keystrokes; layout does not affect scoring, but your muscle memory will.
Are ghost runs downloadable? expand_more
Each dash generates a replay file you can download and replay locally or share with friends.
Is there a mobile app? expand_more
TYPE RUNNER runs in any modern browser. Add to home screen for an app‑like experience.
What are the free‑tier limits? expand_more
Free tier includes unlimited dashes, basic leaderboard, and the last five ghost replays. Advanced features require a Pro subscription.
