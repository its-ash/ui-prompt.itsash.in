Questions from the wings

Do I need to know code to use Words in Motion?expand_more

No. The stage is fully visual: drag, scrub, and tune with sliders. Code only appears when you export, and it arrives clean and commented.

What formats can I export?expand_more

Pure CSS keyframes, Lottie JSON, or a 4kb runtime snippet. Every export includes a reduced-motion fallback automatically.

Can I use my own fonts?expand_more

Yes. Upload any variable or static font you are licensed to use. Tour plans include team font hosting with automatic subsetting.
