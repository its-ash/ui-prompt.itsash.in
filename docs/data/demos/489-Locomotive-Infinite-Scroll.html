Common questions

Does it hurt performance on low-end devices?expand_more

No. Flowstate only animates transform and opacity on the compositor thread, and it automatically falls back to native scrolling on touch devices and under reduced-motion preferences.

How does it handle accessibility?expand_more

Content is visible by default without JavaScript, reveals are disabled under prefers-reduced-motion, and all dynamic updates are announced through aria-live regions.

Can I use it with React or Vue?expand_more

Yes. Official wrappers for React, Vue, and Svelte manage the instance lifecycle for you, including cleanup on route changes and updates after hydration.
