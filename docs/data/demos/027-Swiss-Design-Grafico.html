Which browsers does GRID support?add

All current versions of Chrome, Firefox, Edge, and Safari. Exported layouts are standard CSS Grid — no runtime script required.

Can I change the grid after export?add

Yes. Grid parameters live in one token file. Change the token, regenerate the stylesheet, and every dependent rule updates.
