FAQ

Questions, answered

Is Nimbus a framework or a component library?expand_more

Both. Nimbus ships a token layer — colors, radii, shadows, motion — plus a set of framework-agnostic glass components, so it drops into React, Vue or plain HTML without a build step.

How does the dark mode toggle work?expand_more

Dark is the default because the aurora effects are built for it. The toggle flips a single class on the root element, remembers your choice in localStorage, and follows your OS preference on a first visit.

Can I use my own brand colors?expand_more

Yes. Every gradient, glow and focus ring reads from CSS variables, so swapping the aurora palette for your brand colors restyles the entire system — no component edits required.
