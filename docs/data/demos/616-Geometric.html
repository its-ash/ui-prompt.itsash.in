05 / FAQ

Frequently Asked Questions

Quick answers to common inquiries.

Is there a limit on file size for imports?
We support uploads up to 200 MB per file. Larger datasets can be split or accessed via our API.
Can I use the platform offline?
Yes. The Pro and Enterprise tiers include a desktop client that works offline and syncs when you’re back online.
What file formats can I export?
SVG, PNG, JPEG, PDF, and EPS are all available. You can also generate embeddable code snippets.
