Features

The three departments of every issue

Every issue in Nimbus moves through three departments before it reaches a reader. Each one is built on the same typographic spine, so nothing you compose ever drifts off-brand or off-grace — the grid does the policing while you keep the taste. Below, the machinery that carries a manuscript to the masthead, quietly and without a single line of CSS.

01text_fields

Typography Engine

Optical sizing, hanging punctuation, and small caps that survive the trip from InDesign to the browser. Set it once; it stays set everywhere.

02grid_view

Grid Atelier

Twelve-column asymmetry with baseline locks and hairline rules. Drag a folio and the whole layout breathes with it — never a broken measure.

03library_books

Issue Archive

Every issue versioned, searchable, and print-ready. Export a press-quality PDF with one keystroke, or hand off HTML that behaves.

FAQ

Set in plain type

Do I need to know CSS to use Nimbus?expand_more

No. Grids, drop caps, and pull quotes are one-click folios — if you can edit a document, you can edit an issue. CSS is available for the stubborn, never required.

Can I export print-ready files?expand_more

Yes. Every issue exports a press-quality PDF with embedded fonts, true pagination, and bleed marks. Parity with the web version is guaranteed down to the folio.

What happens to my issues if I cancel?expand_more

Your archive stays downloadable for 90 days in PDF and HTML, after which it is permanently deleted. We never hold your typography hostage.
