Common questions

Everything teams usually ask before their first drill-down.

How is Stratum different from a regular dashboard tool?expand_more

Dashboards show fixed slices. Stratum models your metrics as a hierarchy, so every number is an entry point to the level beneath it, with filters and context carried along automatically.

Do viewers need any training?expand_more

No. If someone can follow a breadcrumb trail, they can use Stratum. Clicking a metric drills down, and the back button returns to the previous level exactly as it was left.

Which data sources do you support?expand_more

Postgres, Snowflake, BigQuery, Redshift, and any REST API on all plans. Higher tiers add dbt semantic layer sync and warehouse-native pushdown for large datasets.

How does context preservation actually work?expand_more

Every drill step is recorded as a state snapshot: filters, date range, comparison, and level. Moving up or sharing a link restores that exact snapshot, so two people always see the same thing.

Can I control who sees row-level detail?expand_more

Yes. Permissions apply per level, so a regional manager can drill to detail within their region while seeing only summaries elsewhere. Row-level security rules are enforced at query time.
