Questions, answered

Everything developers usually ask before wiring Traceback into production.

Which platforms does the SDK support?expand_more

JavaScript, TypeScript, Node, Python, Go, Ruby, and mobile runtimes. Source maps and symbol uploads are handled automatically during your build.

How does issue grouping work?expand_more

Traceback fingerprints each exception by stack frame and message, so thousands of occurrences collapse into one actionable issue with full history.

Is my application data safe?expand_more

Yes. Data is encrypted in transit and at rest, PII scrubbing runs before storage, and you control retention windows per project.

Can I self-host Traceback?expand_more

Enterprise plans include a self-hosted deployment option with the same feature set, plus dedicated upgrade support.

What happens if I exceed my event quota?expand_more

We keep collecting and notify you before throttling. You can raise limits instantly or set spike protection to sample high-volume noise.
