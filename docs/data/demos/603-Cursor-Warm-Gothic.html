How it works

From question to merged diff in minutes

No setup rituals, no prompt engineering course. Open a folder and start.

01

Open your project

Point Grimoire at any repository. It indexes your code locally in seconds and keeps the index fresh as you work.

02

Ask or select code

Chat about the whole codebase, or highlight a function and describe the change you want in plain words.

03

Review the diff

Every change arrives as a readable diff with tests run. You stay the author of record on every commit.
