Frequently Asked Questions

How does the bento grid work?

The bento grid uses a flexible 4‑column layout with variable row spans, allowing you to create asymmetric, Apple‑inspired tiles that adapt to any screen size.

Is my data encrypted?

Yes. All data is encrypted in transit with TLS 1.3 and at rest using AES‑256.

Can I export my boards?

Export options include JSON, CSV and PNG snapshots, available on Pro and Enterprise plans.
