Common questions

The short answers, before you ask on the demo call.

How fast is "real time", exactly?expand_more

Metrics reach dashboards in under two seconds from collection on Pro plans. Alert evaluation runs continuously, so threshold breaches notify within the same window.

Does Pulsegrid replace my existing metrics stack?expand_more

No. Pulsegrid ingests from Prometheus, CloudWatch, Datadog, and OpenTelemetry, so you keep your collectors and gain a faster live layer on top.

What happens to my data if I cancel?expand_more

You can export all metrics and alert history for 30 days after cancellation. After that, data is permanently deleted from our systems.

Can I self-host Pulsegrid?expand_more

Enterprise plans include a private-region deployment option that runs inside your cloud account with the same live streaming engine.

How does anomaly detection handle seasonal traffic?expand_more

The model learns weekly and daily patterns per service, so a Friday-night spike reads as normal while the same spike on Tuesday triggers a review.
