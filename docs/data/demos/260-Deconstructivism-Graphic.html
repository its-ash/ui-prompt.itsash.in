05 / FAQ

Questions, answered plainly

Do the exports survive production?

Yes. Every layout compiles to semantic HTML and CSS custom properties — no runtime, no div soup. Reduced-motion and dark-mode variants ship in the same file.

Can I bring my own type?

Map the display, body and mono slots to any family you license. Fragment scales are token-driven, so swapping grotesques keeps the collisions intact.

What if my team prefers the grid?

Strict mode exists: it snaps every tilt to zero and locks spacing to the baseline. We judge you quietly, but the option is there.
