Frequently Asked Questions

What file formats can I export to? expand_more

You can export to .vox (MagicaVoxel), .obj (standard 3D), and .gltf (web/game engines). All exports include your color palette.

Is there a limit to how many cubes I can use? expand_more

The Free tier supports up to 10,000 cubes. Pro and Team tiers offer 100,000+ cubes with performance optimizations for large builds.

Do I need to install anything? expand_more

No! VoxelForge runs entirely in your browser. Works on desktop Chrome, Firefox, Safari, and Edge. Mobile support coming soon.

How does real-time collaboration work? expand_more

Share a link with edit permissions. See others' changes instantly with cursor indicators and color-coded edits.
