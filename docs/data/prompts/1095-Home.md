# Landing Page Build Prompt — "Editorial Broadsheet in a Green Room" Theme

## 1. Project Overview & Theme

Build a complete, single-page landing site for a **fictional** brand/product (invent the name, copy, and imagery — never use any real brand name, logo, trademark, or product name from the source reference). The visual style is an editorial broadsheet reimagined for the web: monumental serif and grotesque headlines, small-caps micro-labels, a single saturated neon green (`#2bee4b`) as a highlighter pen over an otherwise monochrome warm-paper canvas, grayscale duotone-tinted rectangular photo inserts, generous editorial spacing, and a footer that flips to near-black with a full-bleed green band.

**Theme:** Light (warm bone white canvas, not pure white).

**Deliverables:** Separate `index.html`, `style.css`, and `script.js`. No inline `<script>` beyond a single deferred entry-point reference. No inline CSS (`style="..."`) anywhere. Use one consistent class-naming convention (BEM) throughout.

## 2. Strict Architecture Rules

- **CSS-First / Zero Inline CSS:** All styling in `style.css` via class/ID selectors only. HTML stays semantic and style-agnostic.
- **CSS Variables:** Define all tokens in `:root` (and `.dark` / `@media (prefers-color-scheme: dark)`). Required tokens:
  - Colors: `--color-bone-white: #fafffa`, `--color-press-black: #121613`, `--color-typesetter-ink: #000000`, `--color-slate-verdant: #232924`, `--color-newsprint-gray: #516254`, `--color-muted-sage: #c8d2c8`, `--color-highlighter-green: #2bee4b`, `--color-shadow-moss: #93b799`, `--color-echo-green: #c4e4c9`.
  - Semantic aliases: `--bg-primary`, `--bg-secondary`, `--text-primary`, `--text-secondary`, `--text-success`, `--text-error`, `--border-default`, `--border-error`, `--border-success`, `--primary`, `--secondary`.
  - Radius: `--radius-sm: 5px`, `--radius-md: 10px`, `--radius-lg: 14px`.
  - Shadows: `--shadow-lg: rgba(16,94,29,0.45) 1px 8px 20px 0px`, `--shadow-lg-2: rgba(18,146,39,0.25) 1px 8px 20px 0px`.
  - Spacing: `--spacing-4` through `--spacing-190` per spec scale; `--spacing-gap: 20px`; `--section-gap: 80px`.
  - Transitions: `--transition-fast`, `--transition-normal`, `--ease-standard`.
  - Z-index: `--z-dropdown`, `--z-modal`, `--z-toast`.
  - Fonts: `--font-twk-lausanne`, `--font-pp-mondwest`, `--font-editorial-new`, `--font-times`.
  - Type scale tokens: `--text-caption`, `--text-body-sm`, `--text-body`, `--text-subheading`, `--text-heading-sm`, `--text-heading`, `--text-heading-lg`, `--text-display`.
- **Contrast Pairing:** Light backgrounds pair with dark text; dark backgrounds pair with light text — enforce for every theme.
- **Light Mode Background:** Use `#fafffa` (bone white), never pure `#ffffff`.
- **Dark Mode (Mandatory):** Provide dark tokens under `@media (prefers-color-scheme: dark)` and `.dark` class. Seamless variable switching. Persist choice via `localStorage`, falling back to `prefers-color-scheme`; visible toggle with correct `aria-pressed`/`aria-label`.
- **Flexbox & Mobile-First:** All layouts use Flexbox. Every flex container defaults to `align-items: center` unless explicitly justified. Responsive: rows convert to columns on small viewports; no horizontal scrolling.
- **Tailwind CSS:** Use Tailwind (or clean custom CSS via `@layer`/`@apply`) unless another framework requested. Utility classes map to CSS variables or reusable classes (`.btn`, `.card`, `.input-group`).
- **Typography & Icons:** Google Fonts mandatory for text and icons. Text: load TWK Lausanne substitute (Inter), PP Mondwest substitute (Recoleta/Playfair Display), Editorial New substitute (Canela/GT Super), Times fallback. Bind to `--font-*`. Icons: Google Material Symbols only — no inline SVGs or local icon files.

## 3. Component State Requirements

Enforce full state styling for:

- **Buttons:** Default (flex, `align-items: center`, `justify-content: center`, `gap: 0.5rem`, min 44x44px touch target), Hover (brightness/shadow, `cursor: pointer`), Focus (distinct focus ring via CSS vars), Active (`transform: scale(0.97)`), Loading (disabled interactions, CSS spinner/animated Google Icon, no dimension distortion), Disabled (`opacity: 0.5`, greyscale, `cursor: not-allowed`), Success/Error (temporary feedback via `--text-success`/`--text-error`).
  - Primary: `#2bee4b` fill, `#000000` label, TWK Lausanne 11px/550 uppercase, +0.01em tracking, padding 20px 30px, radius 5px, shadow `rgba(16,94,29,0.45) 1px 8px 20px 0`. Never gray shadow.
  - Ghost (dark surfaces): transparent fill, 1px `#fafffa` border, `#fafffa` label, radius 10px, padding 50px 20px.
- **Cards:** Default (flex, subtle borders, elevation via `--bg-secondary`), Hover (elevation/shadow shift or `translateY(-2px)`), Focus-within (border highlight), Loading (skeleton shimmer), Empty state (Google Icon + guidance text).
- **Forms/Inputs:** Empty, Focused (outline ring), Filled, Valid, Invalid, Disabled, Read-only. Flex container wrapping label, input, error feedback.
- **Modals:** Opening/Open/Loading/Success/Error/Closing animated via CSS transitions. Centered flex, backdrop overlay, Google Icon close button, focus trapping, close via Esc/overlay click.

## 4. Core UX & Micro-Interactions

- Responsive by default; fluid sizing; no horizontal overflow.
- Smooth CSS transitions on all state changes (`transition: var(--transition-normal)`), respecting `prefers-reduced-motion`.
- Accessibility: sufficient contrast both themes; never color-only state communication; semantic HTML5; correct ARIA roles/labels; logical DOM/focus order; full keyboard operability; `aria-live` regions for dynamic feedback.
- Mandatory visual feedback on every click/hover/submission.
- Destructive actions visually distinct in both themes.

## 5. Page Sections (in order)

1. **Hero:** Typographic wall. Max-width 1400px centered on `#fafffa`. Headline in PP Mondwest 400 at 165–295px, lineHeight 0.9, letterSpacing -0.04em, color `#121613`. Three grayscale photo tiles (radius 14px) floated inline between lines, filter: `grayscale(1) saturate(1) invert(0.27) sepia(0.07) saturate(10.67) hue-rotate(80deg) brightness(1.02) contrast(0.83)`. Navigation: minimal top bar — wordmark left ("New Form"-style lockup: TWK Lausanne bold brand name with 2px green underline beneath first word), "Menu" with green three-bar icon right. Micro-labels TWK Lausanne 11px/550 uppercase +0.01em.
2. **Features (3 cards):** 3-column grid (responsive). Each card: muted sage category tag (TWK Lausanne 14px/350, +0.01em), headline, body. Flat, no box-shadow, hairline borders or none. 20px element gap, 80px section gap.
3. **How It Works (3 steps):** Numbered steps with stat callouts in Newsprint Gray `#516254` at display scale. TWK Lausanne body.
4. **Testimonials:** Editorial pull-quotes in Editorial New (serif, weight 300) italic-leaning, 60–140px. Attribution in TWK Lausanne micro-labels.
5. **Pricing (3 tiers):** Three tiers. Middle/featured tier uses Highlighter Green accent. Ghost buttons on dark; filled green on light. Use `.btn`, `.card` classes.
6. **FAQ:** Accordion-style (CSS-driven, JS toggles classes only). Semantic details/summary or div with ARIA. Focus rings, keyboard operable.
7. **Final CTA:** Centered headline + primary green button with green-tinted shadow.
8. **Footer:** Background `#121613`. Small-caps TWK Lausanne 11px/550 `#fafffa` nav columns, 18px/200 body contact lines. Followed by full-bleed `#2bee4b` accent band (~640px tall) containing wordmark "N" in white TWK Lausanne bold top-left with 50px padding. Band is the closing signature.

## 6. Imagery & Type Rules

- All photos: grayscale filter chain above, cropped ~200×140px, radius 14px, floated inline between display-type lines. No full-bleed hero image, no overlapping media.
- Icons: minimal stroke marks in `#000000` or `#fafffa`. Google Material Symbols only.
- Display headlines: PP Mondwest (serif) for biggest statements; Editorial New (lighter serif) for italic pull-quotes; TWK Lausanne (grotesque) for UI and 96–155px sub-display. Body/micro-labels in TWK Lausanne 11–18px. Times fallback for rendered browser text.
- Body copy max 18px. Content max-width 1400px. Section gap 80px, element gap 20px.
- No second saturated accent. No rounded pills (9999px) on primary button (use 5px). No box-shadow on cards/content (elevation only on green button). No sans-serif display headlines. No full-color photos.

## 7. Copy & Brand

All user-facing copy in English. Invent a fictional brand name, product, and copy. Never use the real brand name, logo, trademarks, or product names from the reference. Placeholders allowed only where content genuinely unspecified.

## 8. Accessibility Checklist

- Semantic HTML5 landmarks (header, nav, main, section, footer).
- Sufficient contrast in light and dark modes.
- ARIA roles/labels on custom widgets (menu, accordion, modal, toggle).
- Logical DOM/focus order; full keyboard operability.
- `aria-live` regions for dynamic feedback (form errors, toasts, loading).
- Focus rings on all interactive elements.
- Respect `prefers-reduced-motion`.
