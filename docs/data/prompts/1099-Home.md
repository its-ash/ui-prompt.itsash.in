# Landing Page Build Prompt — "Home" Editorial Atelier Theme

## 1. Role & Objective
You are an expert frontend engineer. Build a complete, responsive landing page from scratch using **separate `index.html`, `style.css`, and `script.js` files** (no inline `<script>` blocks beyond a single deferred entry-point reference). The visual style is a **warm editorial atelier**: cream-paper canvas, charcoal ink, one ember-orange accent, magazine-like breathing room. **Invent a fictional brand name, product, and copy** — never use the real brand name "Parallel", its logo, trademarks, or product names. All user-facing copy must be in English.

## 2. Strict Architecture Rules

**2.1 CSS-First, Zero Inline CSS**
- All styling lives in `style.css`. Forbid `style="..."` attributes in HTML.
- Target via class/ID selectors only. Keep HTML semantic and styling-agnostic.

**2.2 CSS Variables & Theme Tokens**
Define all tokens in `:root` (and theme classes) as CSS variables:
- Colors: `--primary`, `--secondary`, `--bg-primary`, `--bg-secondary`, `--text-primary`, `--text-secondary`, `--text-success`, `--text-error`, `--border-default`, `--border-error`, `--border-success`, plus the theme-specific tokens below.
- Theme-specific color tokens:
  - `--color-cream-paper: #e4dfd9` (page canvas)
  - `--color-pure-white: #fefefe` (use `#fefefe`, not `#ffffff`, where near-white is needed)
  - `--color-charcoal-ink: #000000`
  - `--color-near-black: #050505`
  - `--color-pressed-graphite: #171717`
  - `--color-slate: #737373`
  - `--color-iron: #4b4b4b`
  - `--color-stone: #999694`
  - `--color-pewter: #666666`
  - `--color-fog: #c7c7c7`
  - `--color-ember: #ff6a1f` (accent — status indicators, hero period, match-score badges only)
- Contrast pairing: light backgrounds pair with dark text; dark backgrounds pair with light text — enforce for every theme.
- Border radius/shadows: `--radius-sm: 8px`, `--radius-md: 12px`, `--radius-lg: 20px`, `--radius-pill: 9999px`, `--shadow-soft: rgba(0,0,0,0.07) 0px 6px 27px 0px`.
- Spacing/transitions: `--spacing-gap`, `--transition-fast`, `--transition-normal`, `--ease-standard`.
- Elevation: `--z-dropdown`, `--z-modal`, `--z-toast`.

**2.3 Mandatory Dark Mode**
- Define dark mode tokens under `@media (prefers-color-scheme: dark)` and/or a `.dark` class.
- Background and text variables switch seamlessly without HTML restructuring.
- Persist user choice via `localStorage`, falling back to `prefers-color-scheme` on first visit; provide a visible toggle with correct `aria-pressed`/`aria-label`.

**2.4 Flexbox Layout & Mobile-First**
- Use Flexbox (`display: flex`) for all layout structures.
- Every flex container defaults to `align-items: center` unless explicitly justified.
- Mobile-responsive out of the box (rows → columns on small viewports); no horizontal scrolling.

**2.5 Framework**
- Use Tailwind CSS or clean custom CSS driven by Tailwind `@layer`/`@apply`. Utility classes map to CSS variables or reusable class names (`.btn`, `.card`, `.input-group`).

**2.6 Typography & Icons (Google Fonts Mandatory)**
- Text: Google Fonts — Rules Font substitute `Inter` weight 500 for headings; `Inter`/`Söhne`/`Geist` for UI sans. Bind to `--font-base` and `--font-display`.
- Icons: Google Material Symbols/Icons only. No raw inline SVGs or local icon files.

## 3. Component Specifications

**3.1 Buttons**
- Default: flex, `align-items: center`, `justify-content: center`, `gap: 0.5rem`, min touch target 44x44px.
- Hover: brightness/shadow shift, `cursor: pointer`.
- Focus: distinct focus ring via CSS variables.
- Active: `transform: scale(0.97)`.
- Loading: disables interaction, CSS spinner or animated Google Icon, no dimension distortion.
- Disabled: `opacity: 0.5`, greyscale, `cursor: not-allowed`.
- Success/Error: temporary styles via `--text-success`/`--text-error`.
- Variants: Ghost (no bg/border, text only), Filled Dark (Pressed Graphite bg, white text, 8px radius, 18px/10px padding, optional soft shadow).

**3.2 Cards**
- Default: flex layout, subtle borders, elevation via `--bg-secondary` and variables.
- Hover: shadow shift or `transform: translateY(-2px)`.
- Focus-within: highlight border when child link/button focused.
- Loading (Skeleton): shimmer animation in CSS, no layout jumps.
- Empty State: Google Icon + guidance text.
- Feature Card: white surface, 20px radius, 32px padding, soft shadow. Heading in display font weight 500 at 23px (letter-spacing -0.46px), body in UI sans at 16px weight 400 in Slate.

**3.3 Forms & Inputs**
- States: Empty, Focused (outline ring), Filled, Valid (success border/icon), Invalid (error border, red text, error icon), Disabled, Read-only.
- Structure: flex container wrapping label, input, dedicated error feedback container.
- Hero Search Input: white surface, 12px radius, Fog border, 16-24px horizontal padding, placeholder in Stone at 16px, circular 40px arrow button (Charcoal Ink bg, white arrow icon).

**3.4 Modal / Popup**
- States: Opening, Open, Loading, Success/Error, Closing (CSS transitions).
- Centered flex (`align-items: center`), backdrop overlay, Google Icon close button, focus trapping, close via Esc or overlay click.

**3.5 Navigation Bar**
- Transparent/cream bg, logo in display font weight 500 at 28px Charcoal Ink left; pill toggle center; ghost "Sign in" + filled "Find work" right. Comfortable vertical padding.

**3.6 Pill Toggle**
- Segmented control, 12px radius, active tab white with soft shadow, inactive transparent on cream. Text 14px weight 500 Charcoal Ink. 8px gap, 18px horizontal padding per segment.

**3.7 Job Tag Chips**
- Pill shape 9999px radius, white/cream bg, 1px Fog border, 10-12px vertical / 14-18px horizontal padding, text 14px weight 500.

**3.8 Live Status Indicator**
- Ember Dot bullet + text in UI sans 14px weight 500 Charcoal Ink.

**3.9 Section Heading Block**
- Display font weight 500 at 28px Charcoal Ink, left-aligned, followed by body in UI sans 16px Slate. Max-width ~500px.

**3.10 Full-Bleed Image Card**
- Edge-to-edge photo, 16-20px radius, Pressed Graphite scrim ~40% opacity, centered CTA floating at bottom.

## 4. Core UX & Micro-Interactions
- Responsive by default; fluid sizing; no horizontal overflow.
- CSS transitions on all state changes (`transition: var(--transition-normal)`), respecting `prefers-reduced-motion`.
- Accessibility: sufficient contrast both modes; never rely on color alone; semantic HTML5; correct ARIA roles/labels; logical DOM/focus order; full keyboard operability; `aria-live` regions for dynamic feedback.
- Mandatory visual feedback on every click/hover/submission.
- Destructive actions visually distinct in both themes.

## 5. Typography Scale
- Display: 69px, weight 500, line-height 1.10, letter-spacing -1.38px (hero headlines only).
- Heading: 28px, weight 500, line-height 1.40, letter-spacing -0.56px.
- Heading-sm: 23px, weight 500, line-height 1.40, letter-spacing -0.46px.
- Subheading: 19px, weight 400/500, line-height 1.40, letter-spacing -0.38px.
- Body: 16px, weight 400, line-height 1.50, letter-spacing -0.32px.
- Caption: 14px, weight 500, line-height 1.20, letter-spacing -0.28px.

## 6. Page Structure (Sections)
1. **Hero** — full-bleed dark photography with warm amber lighting; centered display headline (69px) followed by Ember Dot period; subtext 19px white 90% opacity; hero search input; "I'm not sure" secondary text link below.
2. **Features** — 3 feature cards in grid on cream canvas (white surface, 20px radius, 32px padding, soft shadow). Each: mini product UI mockup top, heading + body bottom.
3. **How It Works** — 3 steps on cream canvas, editorial layout.
4. **Testimonials** — editorial quote blocks.
5. **Pricing** — 3 tiers.
6. **FAQ** — accordion-style questions.
7. **Final CTA** — full-bleed image card with scrim and floating button.
8. **Footer** — secondary links.

## 7. Design Rules (Do/Don't)
- Do use Cream Paper `#e4dfd9` as default page background for non-photography sections.
- Do apply display font weight 500 at 28px/69px for all headlines with -0.02em letter-spacing; never weight 600+.
- Do set card radius 20px, buttons 8px, inputs 12px, pills 9999px.
- Do use Ember Dot `#ff6a1f` only for live-status, hero period, match-score badges — never large fills/backgrounds/button states.
- Do set card padding 32px.
- Do use Pressed Graphite `#171717` for filled button bg with white text.
- Do maintain section gaps 24-32px, element gaps 8px.
- Don't introduce additional chromatic colors.
- Don't use bold (700+) for headlines.
- Don't apply shadows beyond the single soft pattern.
- Don't use pure black `#000000` as filled button bg when Pressed Graphite available.
- Don't set radius to 4px/0px on cards/buttons.
- Don't use more than one chromatic element per viewport.
- Don't apply 69px display size to subheadings/body.

## 8. Imagery & Surfaces
- Photography is dominant: full-bleed cinematic crops, deep blacks, warm amber lighting, people in motion, shallow DOF. Used as hero bg, content cards, section dividers. No illustrations/3D renders/abstract graphics (except the metallic 3D "P"-style brand mark as a signature artifact — invent your own abstract brand mark).
- Surfaces: Level 0 Cream Paper (canvas), Level 1 Pure White (cards/inputs), Level 2 Pressed Graphite (dark UI/scrims/buttons), Level 3 Charcoal Ink (max-contrast overlays).
- Icons: line-based, minimal stroke, monochrome Charcoal Ink.
