## 1. Brand & Content Rules
- Invent a fictional brand name, product, and all user-facing copy. Never use the real brand name "1X Tech", its logo, trademarks, or product names anywhere in the page.
- All user-facing copy must be in English.
- No lorem-ipsum-only submissions; use realistic, invented copy for every section.

## 2. Theme: "Quiet Domestic Cinema" (Light-First with Mandatory Dark Mode)
- **Light mode (default):** Page canvas uses a warm off-white `#f7f7f7` (Gallery White), not pure white. Reserve charcoal `#222222` for full-bleed cinematic chapters.
- **Dark mode:** Must be fully defined under `@media (prefers-color-scheme: dark)` and a `.dark` class selector. Dark mode must switch background/text CSS variables seamlessly. Persist user choice via `localStorage`, falling back to `prefers-color-scheme` on first visit. Provide a visible toggle control with correct `aria-pressed` and `aria-label`.
- **Contrast pairing:** Every light background token pairs with a dark text token; every dark background token pairs with a light text token.

## 3. CSS Architecture (Strict)
- All styling lives in `style.css`. Zero inline `style="..."` attributes.
- Target all design via class/ID selectors only. Keep HTML semantic and styling-agnostic.
- Store all visual tokens in `:root` (and theme classes) using CSS variables:
  - Colors: `--primary`, `--secondary`, `--bg-primary`, `--bg-secondary`, `--text-primary`, `--text-secondary`, `--text-success`, `--text-error`, `--border-default`, `--border-error`, `--border-success`, plus theme-specific tokens: `--color-gallery-white: #f7f7f7`, `--color-paper-white: #fefefe`, `--color-charcoal-field: #222222`, `--color-graphite: #474747`, `--color-quiet-gray: #8f8f8f`, `--color-steel-gray: #808080`, `--color-ink: #0a0a0a`, `--color-control-mist: #d6d6d6`.
  - Note: Where a white/near-white is needed, use `#fefefe` instead of `#ffffff`.
  - Border radius: `--radius-sm`, `--radius-md`, `--radius-lg`, plus `--radius-pill: 9999px`, `--radius-media: 80px`, `--radius-none: 0px`.
  - Shadows: `--shadow-sm`, `--shadow-md` (but elevation is avoided; keep shadows minimal/none for cards).
  - Spacing: `--spacing-gap`, `--spacing-8`, `--spacing-16`, `--spacing-24`, `--spacing-32`, `--spacing-40`, `--spacing-80`.
  - Transitions: `--transition-fast`, `--transition-normal`, `--ease-standard`.
  - Elevation/stacking: `--z-dropdown`, `--z-modal`, `--z-toast`.
  - Typography: `--font-base` (bind to Google Font), plus type-scale tokens: `--text-utility-label`, `--text-global-nav`, `--text-utility-button`, `--text-supporting-detail`, `--text-utility-text`, `--text-order-button`, `--text-product-identifier`, `--text-section-body`, `--text-hero-product-title`, `--text-section-heading`.
- Enforce one consistent class-naming convention (BEM) across the entire deliverable.

## 4. Typography & Icons
- Use Google Fonts for text: load ABCDiatype substitutes (Arial/Helvetica Neue fallbacks via Google Font "Inter" or similar clean sans) via `<link>` or `@import`. Bind to `--font-base`. Since ABCDiatype is proprietary, use "Inter" as the Google Font substitute with weights 400, 500, 700.
- Use Google Material Symbols/Icons for all icons. No raw inline SVGs or local icon files.

## 5. Layout Standards
- Use Flexbox (`display: flex`) for all layout structures. Every flex container must default to `align-items: center` unless explicitly justified.
- Mobile-first: convert rows to columns on small viewports. Prevent horizontal scrolling.
- Use Tailwind CSS (via CDN) or clean custom CSS driven by Tailwind `@layer`/`@apply`. All utility classes must map back to CSS variables or reusable class names (`.btn`, `.card`, `.input-group`).

## 6. Component Specifications

### Buttons
- Default: flex, `align-items: center`, `justify-content: center`, `gap: 0.5rem`, min touch target 44x44px.
- Hover: brightness/shadow shift, `cursor: pointer`.
- Focus: distinct focus ring via CSS variables.
- Active: `transform: scale(0.97)`.
- Loading: disables interactions, prevents double-clicks, renders CSS spinner or animated Google Icon without distorting dimensions.
- Disabled: `opacity: 0.5`, greyscale, `cursor: not-allowed`.
- Success/Error: temporary feedback via `--text-success` / `--text-error`.
- Pill controls: `border-radius: 9999px`, padding `6px 12px`.
- Dark filled order pill: Graphite background, Paper White text.
- White hero order pill: Paper White background, Graphite text.
- Muted utility pill: Control Mist or transparent, Graphite text, 1px `#e5e5e5` border, 9999px radius.
- Bare text control: transparent, Ink/Graphite text, 0px radius, no padding.

### Cards (Unframed)
- Transparent background, 0px radius, no shadow, no internal padding. Distinguish via image scale, whitespace, text alignment.
- Hover: subtle transform `translateY(-2px)` if interactive.
- Focus-within: highlight border when child receives focus.
- Loading (Skeleton): shimmer animation in CSS.
- Empty state: Google Icon + guidance text.

### Forms & Inputs
- States: Empty, Focused (outline ring), Filled, Valid (success border/icon), Invalid (error border, red text, error icon), Disabled, Read-only.
- Structure: flex container wrapping label, input, error feedback container.

### Modal / Popup
- States: Opening, Open, Loading, Success/Error, Closing (CSS transitions).
- Centered flex container, backdrop overlay, Google Icon close button, keyboard focus trapping, close via Esc or overlay click.
