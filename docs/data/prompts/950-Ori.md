# Coding AI Prompt — Ori-Themed Landing Page (Fictional Brand)

You are a senior front-end engineer. Build a complete, production-quality landing page for a **fictional** brand (invent a name, product, and copy — never use "Ori", "Radiant", or any real trademark/logo/product name from the source spec). The visual style is "server-room at midnight": pure black canvas, whisper-weight white typography, and a single saturated orange that ignites action. Deliver three separate files: `index.html`, `style.css`, `script.js`. No inline `<script>` blocks beyond a single deferred entry-point reference. Use one consistent class-naming convention (BEM) across the entire deliverable.

## 1. Core Architecture Rules

**1.1 CSS-First & Zero Inline CSS**
- All styling lives in `style.css`. Forbid `style="..."` in HTML.
- Target via class/ID selectors only. Keep HTML semantic and styling-agnostic.

**1.2 CSS Variables & Theme Tokens**
Define in `:root` (and `.dark` / `@media (prefers-color-scheme: dark)`):
- Colors: `--color-ember-orange: #ff4f2b`, `--color-void-black: #000000`, `--color-carbon: #1a1a1a`, `--color-graphite-border: #3c3c3c`, `--color-steel-mid: #737373`, `--color-fog-light: #bfbfbf`, `--color-bone-white: #f5f5f5`. Map to semantic tokens: `--primary`, `--secondary`, `--bg-primary`, `--bg-secondary`, `--text-primary`, `--text-secondary`, `--text-success`, `--text-error`, `--border-default`, `--border-error`, `--border-success`.
- Contrast pairing: light backgrounds pair with dark text and vice versa in every theme.
- Light-mode background must not be pure white; use `#fefefe` where near-white is needed. (This theme is dark-first; light mode is a fallback variant.)
- Radius/shadows: `--radius-sm: 0px`, `--radius-md: 0px`, `--radius-lg: 0px`, `--shadow-sm`, `--shadow-md` (shadows defined but unused for elevation).
- Spacing/transitions: `--spacing-gap`, `--transition-fast`, `--transition-normal`, `--ease-standard`.
- Elevation/stacking: `--z-dropdown`, `--z-modal`, `--z-toast`.

**1.3 Mandatory Dark Mode**
- Provide dark tokens under `@media (prefers-color-scheme: dark)` and/or `.dark`.
- Seamless variable switching, no HTML restructuring.
- Persist choice via `localStorage`, fall back to `prefers-color-scheme` on first visit. Visible toggle with correct `aria-pressed`/`aria-label`.

**1.4 Flexbox & Mobile-First**
- Use Flexbox for layout. Every flex container defaults to `align-items: center` unless justified.
- Mobile-responsive out of the box (rows → columns on small viewports). No horizontal scroll.

**1.5 Framework**
- Tailwind CSS (or clean custom CSS via `@layer`/`@apply`). Utility classes map to CSS variables or reusable classes (`.btn`, `.card`, `.input-group`).

**1.6 Typography & Icons (Google Fonts Mandatory)**
- Text: Google Fonts. Use Inter as substitute for TWK Everett/Switzer; JetBrains Mono for Chivo Mono. Bind to `--font-base` etc. Include `<link>`/`@import`.
- Icons: Google Material Symbols/Icons only. No inline SVGs or local icon files.

## 2. Style Tokens (Ori)

**Fonts:** TWK Everett (substitute Inter) weights 300/400/700, sizes 24–96px, line-height 0.95–1.30, letter-spacing -0.011em. Switzer (substitute Inter) weight 400, 16/18px, line-height 1.40. Chivo Mono (substitute JetBrains Mono) weight 400, 14/16px, line-height 1.00–1.40.

**Type scale tokens:** `--text-caption` 14px/1.2, `--text-body` 16px/1.4, `--text-subheading` 18px/1.4, `--text-heading-sm` 24px/1.3/-0.26px, `--text-heading` 36px/1.2/-0.4px, `--text-heading-lg` 48px/1.1/-0.53px, `--text-display` 72px/1/-0.79px, `--text-display-lg` 96px/0.95/-1.06px.

**Spacing (4px base):** 4,8,16,20,24,32,40,48,56,80,92,180 px. Section gap 48–80px. Card padding 24px. Element gap 16px. Page max-width 1280px.

**Radius:** 0px on everything (buttons, cards, inputs, badges). Sharp rectangular geometry is structural.

**Elevation:** No shadows. Depth via surface color (black → carbon) and 1px hairlines (#3c3c3c or #bfbfbf).

## 3. Component Specifications

**Buttons:**
- Filled CTA: `#ff4f2b` bg, `#000000` text, 14px Chivo Mono uppercase, 8px 16px padding, 0 radius, no border.
- Ghost: transparent bg, 1px solid `#f5f5f5` border, `#f5f5f5` text, 14px Chivo Mono uppercase, 8px 16px padding, 0 radius. Hover inverts (fills `#f5f5f5`, text `#000000`).
- All states: default, hover (brightness/shadow + cursor pointer), focus (distinct ring via CSS vars), active (scale 0.97), loading (spinner, no dimension change, disabled), disabled (opacity 0.5, greyscale, not-allowed), success/error (via `--text-success`/`--text-error`).
- Min touch target 44x44px. Flex layout with `align-items: center`, gap 0.5rem.

**Cards (News/Blog):** `#000000` bg, no border/shadow. Full-bleed image top (no radius). 24px padding below. Author meta 12–14px Chivo Mono uppercase `#f5f5f5`. Title TWK Everett 400 24px `#f5f5f5`. Excerpt 14px Switzer `#bfbfbf`, 2–3 line clamp. 'READ MORE' 14px Chivo Mono `#ff4f2b`. Interactive states: hover (translateY -2px), focus-within, skeleton loading, empty state with Google Icon.

**Inputs (Dark):** bg `#1a1a1a`, 1px solid `#3c3c3c`, 0 radius. Text 14–16px Switzer `#f5f5f5`. Placeholder `#737373`. Focus: border shifts to `#ff4f2b` (no visible ring). States: empty, focused, filled, valid, invalid, disabled, read-only. Flex container with label, input, error feedback.

**Modal:** centered flex, backdrop, Google Icon close, Esc/overlay close, focus trap, animated states (opening/open/loading/success/error/closing).

**Announcement Bar:** full-bleed `#1a1a1a`, centered 14px Switzer `#f5f5f5`, 4–8px vertical padding. Inline links `#ff4f2b`. No radius.

**Navigation:** transparent or `#000000` bg, 40px horizontal padding. Wordmark left in 16px Chivo Mono 400. Nav items 14px Chivo Mono uppercase `#f5f5f5`, 16–24px gap. Contact CTA filled orange. Login ghost.

**Hero:** full-viewport `#000000`, optional dark photographic overlay. Headline TWK Everett 300 72–96px `#f5f5f5` with one word/phrase in `#ff4f2b`. Body 16–18px Switzer `#f5f5f5`, max-width ~540px. Dual CTA row (filled + ghost), 16px gap.

**Full-Bleed Statement Section:** full-width `#ff4f2b`, no vertical padding (bleeds). Centered TWK Everett 400 36–48px `#000000`. Single sentence. Visual interruption.

**Section Header:** left-aligned title TWK Everett 300 48–60px `#f5f5f5`. Optional numeric counter right-aligned Chivo Mono 16px `#f5f5f5`. 40–48px space below.

**Footer:** `#000000`, 40px+ padding. Wordmark + nav columns 14px Chivo Mono `#f5f5f5` with `#737373` secondary. Flat columns, no dividers.

## 4. Page Sections to Build

1. Announcement Bar (system message)
2. Primary Navigation
3. Hero Section
4. Features (3 cards grid)
5. How It Works (3 steps)
6. Testimonials
7. Pricing (3 tiers)
8. FAQ
9. Final CTA
10. Footer with secondary links

Plus a full-bleed statement band somewhere in the rhythm (black → orange → black).

## 5. UX & Micro-Interactions (Global)

- Responsive by default, fluid sizing, no horizontal overflow.
- CSS transitions on all state changes (`transition: var(--transition-normal)`), respect `prefers-reduced-motion`.
- Accessibility: sufficient contrast both modes, never color-only state, semantic HTML5, correct ARIA roles/labels, logical focus order, full keyboard operability, `aria-live` for dynamic feedback.
- Mandatory visual feedback on every click/hover/submission.
- Destructive actions visually distinct in both themes.

## 6. Copy & Content

- All user-facing copy in English. Invent a fictional brand, product, and realistic copy (no lorem-ipsum-only where real labels are needed; placeholders only where unspecified).
- No real brand names, logos, trademarks, or product names.

## 7. Do's and Don'ts (Style)

Do: 0px radius everywhere; TWK Everett 300 at 60–96px for hero/section headlines; Chivo Mono 14px for labels/nav/buttons/metadata; ration `#ff4f2b` for CTAs, one full-bleed band, key emphasis words; `#f5f5f5` on `#000000` primary text; alternate black/orange sections; 1px hairlines, never shadows.

Don't: no radius at all (even 2–4px); no drop shadows/glows/blurred elevation; no `#ff4f2b` for body text/decorative fills; no headline weights 700/900 (300–400 only); no pill buttons; no gradients/pastels/warm secondaries; no lifestyle photography/illustrations/decorative iconography — only dark architectural/infrastructure photography.

## 8. Deliverables

- `index.html`, `style.css`, `script.js`.
- BEM naming throughout.
- No unrequested placeholders where real copy was supplied.
