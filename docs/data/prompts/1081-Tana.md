# Landing Page — Tana Theme (Fictional Brand)

You are an expert frontend developer. Build a complete, production-ready landing page for a **fictional** SaaS product. Do NOT use the name "Tana", its logo, trademarks, or product names anywhere. Invent a fictional brand name, product, and all user-facing copy in English. Reuse only the visual style described below.

## 1. Architecture & Rules

**1.1 CSS-First, Zero Inline CSS**
- All styling lives in `style.css`. No `style="..."` attributes anywhere.
- Target elements via class/ID selectors only. Keep HTML semantic and styling-agnostic.

**1.2 CSS Variables & Tokens**
Define all tokens in `:root` and a `.dark`/media-query block. Required tokens:

Colors (dark theme default):
- `--color-void: #000000`
- `--color-charcoal: #0e0e0e`
- `--color-bone: #f0eded`
- `--color-ash: #b3b3b3`
- `--color-smoke: #808080`
- `--color-graphite: #606060`
- `--color-lime-signal: #e1f0bd`

Light mode fallback (under `@media (prefers-color-scheme: light)` and/or `.light`): invert to a light canvas with dark text, keeping lime as the single accent. Enforce contrast pairing for every theme.

Also define: `--radius-sm`, `--radius-md` (10px), `--radius-lg`, `--shadow-sm`, `--shadow-md` (none/flat), `--spacing-gap`, `--transition-fast`, `--transition-normal`, `--ease-standard`, `--z-dropdown`, `--z-modal`, `--z-toast`, `--font-base`.

**1.3 Dark Mode Support**
- Provide dark tokens under `@media (prefers-color-scheme: dark)` and `.dark` class.
- Persist user choice via `localStorage`, falling back to `prefers-color-scheme` on first visit.
- Include a visible toggle with correct `aria-pressed`/`aria-label`.

**1.4 Flexbox & Mobile-First**
- All layouts use Flexbox. Every flex container defaults to `align-items: center` unless justified.
- Mobile-responsive: rows become columns on small viewports. No horizontal scroll.

**1.5 Tailwind CSS**
- Use Tailwind (or `@layer`/`@apply` with custom CSS). Utility classes map to CSS variables or reusable classes (`.btn`, `.card`, `.input-group`).

**1.6 Typography & Icons**
- Google Fonts only. Text: Inter (substitute for SF Pro) + Playfair Display (substitute for tanaClassic). Bind to `--font-base`/`--font-display`.
- Icons: Google Material Symbols. No inline SVGs or local icon files.

## 2. Design Tokens

**Fonts**
- Body/UI: Inter (weights 300, 400), sizes 13–29px, letter-spacing 0.01em, line-height 1.20/1.40/1.50/1.75.
- Display: Playfair Display (weights 350/400), sizes 17/19/38/42/48/84px, letter-spacing -0.045em at 84px (-3.78px), -0.030em at 38–48px.

**Type scale tokens:** `--text-caption` (13px/1.2), `--text-body-sm` (16px/1.5), `--text-body` (18px/1.5), `--text-body-lg` (21px/1.75), `--text-subheading` (24px/1.2), `--text-heading-sm` (29px/1.4), `--text-heading` (38px/1.2/-1.14px), `--text-heading-lg` (48px/1.25/-1.44px), `--text-display` (84px/1.1/-3.78px).

**Spacing:** base 4px. Scale: 8, 12, 16, 24, 32, 36, 40, 48, 96, 112, 128, 160px.

**Radius:** tags 0px (pentagon clip-path), cards 0px, images 10px, buttons 10px.

**Layout:** max-width 1040px, section gap 32–40px, card padding 16–24px, element gap 6–8px.

## 3. Components

**Pentagon Category Tag:** `clip-path: polygon(0 50%, 12px 0, 100% 0, 100% 100%, 12px 100%)`, fill `--color-bone`, text `#000000` 13–15px Inter 400, tracking 0.01em, padding 8px 12px 8px 16px. No border/radius.

**Lime CTA Button:** filled pill, bg `--color-lime-signal`, text `#000000` 15px Inter 400, radius 10px, padding 6px 12px. No border/shadow. Reserved for the single most important action per screen.

**Ghost Text Link:** no bg/border, text `--color-ash`/`--color-smoke` 13–15px, hover brightens to `--color-bone`. No underline default.

**Announcement Bar:** full-width, bg `--color-bone`, text `#000000`, tight 6–8px vertical padding.

**Nav Header:** transparent over void. Left: small wordmark in bone. Right: single Material Symbol icon in bone. No links/hamburger.

**Hero Headline Block:** centered, display title 84px Playfair 400 bone -3.78px tracking; subhead 18–21px Inter 400 ash 1.50–1.75 lh; CTA stack (Lime button + Ghost link, 8px gap).

**Editorial Image with Orbiting Tags:** centered ~300–350px image, 10px radius, pentagon tags scattered around.

**Section Heading:** 38–48px Playfair 400 bone, -1.14 to -1.44px tracking; body 18–21px Inter 400 ash below, 24–32px gap.

**AI Testimonial Block:** centered, quote 18–21px Playfair/Inter 400 bone italic 1.50–1.75 lh, max 600px; attribution 13–15px Inter 400 smoke. 32–40px between quotes. No quotation marks.

**Body Prose Block:** 17–19px Inter 400 ash, 1.75 lh, max-width 640px, paragraph spacing 16–24px.

**Utility Icon Button:** no bg/border, icon bone 16–20px, 8px padding.

## 4. Component States (enforce for all interactive elements)

Buttons: default, hover (brightness/shadow + cursor pointer), focus (visible ring via CSS vars), active (scale 0.97), loading (spinner, disabled, no double-click), disabled (opacity 0.5, greyscale, not-allowed), success/error (temporary, via `--text-success`/`--text-error`).

Cards: default, hover (translateY -2px), focus-within (border highlight), loading skeleton (shimmer), empty state (icon + guidance).

Forms/inputs: empty, focused, filled, valid, invalid, disabled, read-only — with dedicated error container.

Modals: opening/open/loading/success-error/closing (CSS transitions), centered flex, backdrop, Material Symbol close, Esc/overlay close, focus trap.

## 5. UX Rules

- Responsive by default, fluid sizing, no horizontal overflow.
- CSS transitions on all state changes (`transition: var(--transition-normal)`), respect `prefers-reduced-motion`.
- Accessibility: sufficient contrast both themes; never color-only state; semantic HTML5; ARIA roles/labels; logical focus order; full keyboard operability; `aria-live` for dynamic feedback.
- Mandatory visual feedback on every click/hover/submission.
- Destructive actions visually distinct in both themes.
- Lime accent (`#e1f0bd`) used ONLY for the single primary CTA per screen — never links, icons, tags, decoration, backgrounds beyond CTA.
- No box-shadows/glows/blur; depth via surface tone shifts.
- No pure white text; use bone `#f0eded`.
- Radius only 10px (buttons/images) or 0px (everything else).
- Serif headlines always negative tracking.

## 6. Deliverables

- Separate `index.html`, `style.css`, `script.js`. No inline script blocks beyond a single deferred entry point.
- One consistent naming convention (BEM) across all classes.
- No lorem-ipsum-only where real copy is implied; placeholders only where content genuinely unspecified.
- Sections: Hero, Features (3 cards), How It Works (3 steps), Testimonials, Pricing (3 tiers), FAQ, Final CTA, Footer with secondary links.
- All copy in English. Fictional brand name/product throughout.

## 7. Do/Don't Summary

Do: lime only for single primary action; 84px Playfair -3.78px for hero; weight 300 Inter for 24–29px subheadings; pentagon tags orbit imagery pointing left; body lh 1.75 prose / 1.50 UI; 0% colorfulness outside lime CTA; 10px radius buttons/images only, 0px else.

Don't: second accent; shadows/glows/blur; normal/positive serif tracking; weight 500+ Inter subheadings; lime on non-CTA surfaces; pure white text; generic 4px/8px radius.
