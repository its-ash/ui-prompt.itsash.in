# Coding AI Prompt — Ada-Themed Landing Page

## 1. Project Overview & Scope

Build a complete, responsive landing page using the **Ada** visual style system. The page must include these sections in order: Hero, Features (3 cards), How It Works (3 steps), Testimonials, Pricing (3 tiers), FAQ, Final CTA, and Footer with secondary links.

**Fictional Brand Requirement:** Invent a fictional brand name, product, and all copy. Never use the real brand name "Ada," its logo, trademarks, or product names anywhere in the page. All user-facing copy must be written in English.

**File Structure:** Separate `index.html`, `style.css`, and `script.js` files. No inline `<script>` blocks beyond a single deferred entry-point reference.

**Naming Convention:** Use BEM consistently across all classes. No mixing of conventions.

## 2. CSS-First Architecture & Zero Inline CSS

- All styling must live strictly inside `style.css`. No `style="..."` attributes in HTML.
- Target all design properties, layout rules, and states via class or ID selectors only.
- Keep HTML semantic, clean, and agnostic of visual styling.

## 3. CSS Variables & Theme Tokens

Define all tokens in `:root` and under `@media (prefers-color-scheme: dark)` plus a `.dark` class selector.

**Colors (Light Mode):**
- `--color-inkstone: #0a0b0c` — primary text, headings, borders, dark surfaces
- `--color-bone: #f9f9f9` — page canvas, section backgrounds
- `--color-paper: #ffffff` — cards, inputs, elevated panels
- `--color-ash: #d8d8d8` — decorative fills, disabled borders, dividers
- `--color-plum-ash: #392c38` — muted card borders, dark tints
- `--color-forest-depth: #00543d` — primary brand, dark buttons, accent bar
- `--color-periwinkle: #abcbf9` — blue action color, primary CTA fill
- `--color-candy-pink: #ffbbfc` — accent bar, soft washes
- `--color-butter: #fce88b` — accent bar, warmth punctuation

**Theme Variables (mapped):**
- `--primary: var(--color-periwinkle)`
- `--secondary: var(--color-forest-depth)`
- `--bg-primary: var(--color-bone)`
- `--bg-secondary: var(--color-paper)`
- `--text-primary: var(--color-inkstone)`
- `--text-secondary: var(--color-inkstone)` at 70% opacity
- `--text-success`, `--text-error` defined for states
- `--border-default: 1px solid rgba(10,11,12,0.12)`
- `--border-error`, `--border-success` defined

**Dark Mode:** Provide dark mode color tokens under `@media (prefers-color-scheme: dark)` and `.dark` class. Enforce contrast pairing — light backgrounds pair with dark text, dark backgrounds pair with light text. Background and text variables must switch seamlessly without HTML restructuring.

**Theme Switching:** Persist user choice via `localStorage`, falling back to `prefers-color-scheme` on first visit. Provide a visible toggle control with correct `aria-pressed` and `aria-label`.

**Other Tokens:**
- `--radius-sm: 4px`, `--radius-md: 8px`, `--radius-lg: 32px`
- `--shadow-sm`, `--shadow-md` (defined but unused — flat design philosophy)
- `--spacing-gap: 80px` (section gap)
- `--transition-fast: 150ms ease`, `--transition-normal: 250ms ease`, `--ease-standard: cubic-bezier(0.4, 0, 0.2, 1)`
- `--z-dropdown`, `--z-modal`, `--z-toast` for stacking
- `--font-base` bound to Roobert (substitute: Inter, DM Sans, or Söhne)

**Spacing Scale:** `--spacing-4` through `--spacing-176` per the 4px base unit scale (4, 8, 12, 16, 20, 24, 32, 36, 40, 48, 72, 96, 112, 120, 160, 176).

**Light Mode Background:** Use `#f9f9f9` (bone) for canvas, `#ffffff` (paper) for cards. Never use pure `#ffffff` as page background.

## 4. Typography & Icons

- Load Google Fonts for text (Inter as Roobert substitute) via `<link>` or `@import`. Bind to `--font-base`.
- Use Google Material Symbols/Icons for all icons. No raw inline SVGs or local icon files.
- Single weight 400 throughout. Hierarchy via size only. Sizes: 12, 14, 15, 16, 18, 20, 24, 32, 36, 48, 60, 72. Line heights: 1.00–1.56. Letter spacing normal at all sizes.

## 5. Layout & Flexbox Standards

- Use Flexbox for all layout structures. Every flex container must default to `align-items: center` unless explicitly justified.
- Mobile-first responsive design. Convert rows to columns on smaller viewports. Prevent horizontal scrolling.
- Page max-width: 1200px centered column. Full-bleed section bands break to viewport edges.
- Section gap: 80px minimum. Card padding: 24px. Element gap: 8–16px.
- Use Tailwind CSS or clean custom CSS driven by Tailwind's `@layer`/`@apply`. All utility classes map back to CSS variables or reusable class names (`.btn`, `.card`, `.input-group`).

## 6. Component Specifications

### Announcement Bar
- Full-width dark utility bar, ~40px height, `#0a0b0c` background, white text at 14px, left-aligned label, right-aligned dark pill button (`#00543d` bg, white text, 9999px radius, 8px 16px padding).

### Primary Navigation
- Sticky top nav, white bg, ~64px height. Logo left, horizontal nav links at 15px with dropdown chevrons, user avatar icon, dark pill CTA button (`#0a0b0c` bg, white text, 9999px radius, 12px 24px padding, circular arrow icon).

### Hero Section
- Full-bleed heavily blurred photographic gradient background (warm amber/teal organic shapes). Two-column split: left 60% oversized headline at 60–72px, line-height ~1.05, stacked; subtext at 18px at 70% opacity. Right 40%: floating white card (8px radius, 1px `#f9f9f9` border, 24px padding) with chat widget content and dark pill button.

### Logo Strip
- Horizontal row of 7–8 monochrome partner logos on `#f9f9f9`, evenly spaced, `#0a0b0c` at ~60% opacity, 40–60px tall. No heading.

### Stat Cards (4-Color Variant Set)
- White card, 8px radius, no shadow, 24px padding. 4px-wide vertical color bar on full left edge: Forest, Candy Pink, Periwinkle, Butter (one per card). Metric number at 36–48px. Two-line descriptor at 14–16px at 70% opacity.

### Feature Cards (Image Variant)
- Full-bleed photographic image, no internal padding. Dark gradient overlay bottom (transparent → ~40% `#0a0b0c`). White title at 32px, body at 14–16px white at 85% opacity. 48px circular dark button (`#0a0b0c`, white right-arrow, 8px radius) bottom-right.

### Circular Arrow Button
- 48px diameter, `#0a0b0c` bg, white → arrow at 18px, 8px radius. Reusable secondary CTA.

### Section Heading Block
- Centered headline at 36–48px, line-height ~1.2, one or two lines. Optional subtext at 18px at 65% opacity, max-width 640px, centered. No eyebrow, no decorative elements.

### Chat Widget Card
- White card, 8px radius, 1px `#f9f9f9` border, ~24px padding. Partner wordmark top-left, status dots top-right, 32px label, 2–3 lines of conversation text at 14px. Dark pill button adjacent.

### How It Works (3 Steps)
- Three-step layout with numbered indicators, titles, and descriptions. Flexbox row (column on mobile). Use hairline borders, no shadows.

### Testimonials
- Card-based layout with quote text, author name, and role. White cards on `#f9f9f9` canvas. No shadows.

### Pricing (3 Tiers)
- Three pricing cards in a row (stack on mobile). Highlighted tier uses `#abcbf9` accent. Feature lists with check icons (Material Symbols). Pill CTA buttons.

### FAQ
- Accordion-style expand/collapse. Smooth CSS transitions. Keyboard accessible. `aria-expanded` state management.

### Final CTA
- Centered section with large headline, subtext, and primary pill button. `#f9f9f9` or `#ffffff` band.

### Footer
- Multi-column link layout, secondary links, logo, copyright. `#0a0b0c` text at reduced opacity on `#f9f9f9` background.

## 7. Button Component States

- **Default:** Flex layout (`display: flex; align-items: center; justify-content: center; gap: 0.5rem;`), min 44x44px touch target.
- **Hover:** Visual shift (brightness/shadow) with `cursor: pointer`.
- **Focus:** Distinct focus ring using CSS variables.
- **Active/Pressed:** `transform: scale(0.97)`.
- **Loading:** Disabled interactions, CSS spinner or animated Google Icon, no dimension distortion.
- **Disabled:** `opacity: 0.5`, greyscale, `cursor: not-allowed`.
- **Success/Error:** Temporary feedback via `--text-success` / `--text-error`.

## 8. Card Component States

- **Default:** Flexbox layout, subtle borders, elevation via `--bg-secondary` and CSS variables.
- **Hover:** Elevation/shadow shift or `transform: translateY(-2px)`.
- **Focus-within:** Highlight card borders when child receives focus.
- **Loading (Skeleton):** Shimmer animation in CSS, no layout jumps.
- **Empty State:** Google Icon + guidance text fallback.

## 9. Form & Input Requirements

- States: Empty, Focused (outline ring), Filled, Valid, Invalid (error border, red text, error icon), Disabled, Read-only.
- Structure: Flex container wrapping label, input, and error feedback container.

## 10. Modal / Popup Requirements

- States: Opening, Open, Loading, Success/Error, Closing (CSS transitions).
- Centered flex container (`align-items: center`), backdrop overlay, Google Icon close button, keyboard focus trapping, close via Esc or overlay click.

## 11. Core UX & Micro-Interaction Rules

- **Responsive by Default:** Fluid sizing, responsive breakpoints, no horizontal overflow.
- **Smooth Animations:** CSS transitions on all state changes (`transition: var(--transition-normal)`), respecting `prefers-reduced-motion`.
- **Accessibility:** Sufficient contrast in both themes. Never rely solely on color for state. Semantic HTML5, correct ARIA roles/labels, logical DOM/focus order, full keyboard operability, `aria-live` regions for dynamic feedback.
- **Mandatory Visual Feedback:** Every click, hover, or submission triggers visible state change.
- **Destructive Actions:** `.btn-danger` visually distinct in both themes.
- **No Drop Shadows:** Flat design — hairline borders and surface color contrast only.
- **No Gradients on Buttons/Cards/Nav:** Only hero background uses gradient.
- **No Second Typeface or Bold/Light Weights:** Single-weight discipline.
- **Accent Colors:** Only as 4px left-edge bars on stat cards or single filled action surfaces. Never as text colors or broad backgrounds.
- **Radius System:** Cards 8px, inputs 4px, buttons 9999px (pill). Non-negotiable.
- **Section Gaps:** 80px minimum, never below 48px.
- **No Decorative Dividers, Icon Badges, or Eyebrows.**

## 12. Deliverables

- `index.html`, `style.css`, `script.js` — separate files.
- BEM naming throughout.
- No lorem-ipsum-only submissions where real copy is expected; placeholders only where content is genuinely unspecified.
- All user-facing copy in English.

## 13. Dark Mode Persistence

- Implement via `@media (prefers-color-scheme: dark)` and `.dark` class.
- Persist via `localStorage`, fallback to `prefers-color-scheme`.
- Visible toggle with `aria-pressed`/`aria-label`.

## 14. Edit Mode Note

If modifying existing markup, do not introduce new HTML tags or DOM nodes. Define CSS classes only for existing elements. Do not write JS for validation/popups/utilities — ask the user how to handle instead. If a style change requires new markup, stop and ask.
