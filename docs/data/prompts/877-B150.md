# Coding-AI Prompt: B150-Themed Landing Page

## 1. Role & Objective
You are an expert front-end developer. Build a complete, responsive landing page implementing the **B150 "Future Workshop in Film Grain"** visual theme. Use a fictional brand name, product, and copy — never reference or reuse any real brand name, logo, trademark, or product name. Output separate `index.html`, `style.css`, and `script.js` files. No inline `<script>` blocks beyond a single deferred entry-point reference.

## 2. Strict Architecture Rules

### 2.1 CSS-First Architecture & Zero Inline CSS
- Keep all styling strictly inside `style.css`. Forbid `style="..."` attributes in HTML.
- Target all design via class/ID selectors. Keep HTML clean, semantic, and style-agnostic.

### 2.2 CSS Variables & Theme Tokens
Define all tokens in `:root` and `.dark` (plus `@media (prefers-color-scheme: dark)`):

**Colors:**
- `--color-charcoal-ink: #1f1915`
- `--color-workshop-ivory: #f2efe9`
- `--color-paper-white: #fffdf6`
- `--color-studio-white: #ffffff`
- `--color-soft-paper: #f7f5f1`
- `--color-drafting-line: #e6e3dd`
- `--color-quiet-graphite: #6b6661`
- `--color-faded-graphite: #8d8883`
- `--color-signal-coral: #fa725a`

**Generic theme tokens (required):** `--primary`, `--secondary`, `--bg-primary`, `--bg-secondary`, `--text-primary`, `--text-secondary`, `--text-success`, `--text-error`, `--border-default`, `--border-error`, `--border-success`, `--radius-sm`, `--radius-md`, `--radius-lg`, `--shadow-sm`, `--shadow-md`, `--spacing-gap`, `--transition-fast`, `--transition-normal`, `--ease-standard`, `--z-dropdown`, `--z-modal`, `--z-toast`.

Map generic tokens to B150 values (e.g., `--bg-primary: var(--color-workshop-ivory)`, `--text-primary: var(--color-charcoal-ink)`). Enforce contrast pairing for every theme.

**Light mode background:** default page canvas is `#f2efe9` (Workshop Ivory), not pure white. Use `#fefefe` only where a near-white is genuinely needed.

**Spacing & shapes:** base unit 4px. Spacing scale: 4,8,12,16,20,24,32,36,40,48,64,80,96,120,160,208 (as `--spacing-4` … `--spacing-208`). Border radius: cards 16px, links 8px, images 8px, buttons 1440px, media-frame 16px, large-panels 24px. Section gap 40px, card padding 12px, element gap 8px.

### 2.3 Mandatory Dark Mode
- Provide dark mode tokens under `@media (prefers-color-scheme: dark)` and a `.dark` class selector.
- Switch background/text variables seamlessly without HTML restructuring.
- Persist user theme choice via `localStorage`, falling back to `prefers-color-scheme` on first visit. Include a visible toggle control with correct `aria-pressed`/`aria-label`.

### 2.4 Flexbox & Mobile-First
- Build layouts with Flexbox. Every flex container must default to `align-items: center` unless explicitly justified.
- Mobile-responsive out of the box; convert rows to columns on small viewports. Prevent horizontal scrolling.

### 2.5 Tailwind CSS Integration
- Use Tailwind CSS (or clean custom CSS via `@layer`/`@apply`). Utility classes must map back to CSS variables or reusable classes (`.btn`, `.card`, `.input-group`).

### 2.6 Typography & Icons (Google Fonts Mandatory)
- **Text:** Geist (weights 400, 500) and Fragment Mono (weights 400, 500, 600, 700) via Google Fonts `<link>`/`@import`, bound to `--font-geist` and `--font-fragment-mono`. Substitutes: Arial, sans-serif / IBM Plex Mono, monospace.
- **Icons:** Google Material Symbols/Icons only. No raw inline SVGs or local icon files.

Type scale tokens:
- `--text-nav`: Fragment Mono 400, 10px, 1.5 lh, +0.3px tracking
- `--text-micro-label`: Geist 500, 10px, 1.5 lh, -0.3px tracking
- `--text-body`: Geist 400, 12px, 1.7 lh, 0px tracking
- `--text-button-label`: Geist 500, 16px, 1.5 lh, 0.496px tracking
- `--text-section-title`: Geist 500, 32px, 1.12 lh, -0.992px tracking
- `--text-display`: Geist 400, 120px, 0.93 lh, -8.04px tracking

## 3. Component Design Specifications

### 3.1 Button
- Default: flex, `align-items: center`, `justify-content: center`, `gap: 0.5rem`, min 44x44px touch target.
- Hover: brightness/shadow shift, `cursor: pointer`.
- Focus: distinct focus ring via CSS variables.
- Active: `transform: scale(0.97)`.
- Loading: disables interactions, CSS spinner/animated Google Icon, no dimension distortion.
- Disabled: `opacity: 0.5`, greyscale, `cursor: not-allowed`.
- Success/Error: temporary styles via `--text-success`/`--text-error`.

### 3.2 Card
- Default: flex layout, subtle borders, elevation via `--bg-secondary` + CSS variables.
- Hover: shadow shift or `transform: translateY(-2px)`.
- Focus-within: highlight borders when child link/button focused.
- Loading (Skeleton): CSS shimmer, no layout jumps.
- Empty State: Google Icon + guidance text.

### 3.3 Form & Input
- States: Empty, Focused (outline ring), Filled, Valid (success border/icon), Invalid (error border, red text, error icon), Disabled, Read-only.
- Structure: flex container wrapping label, input, dedicated error feedback.

### 3.4 Modal / Popup
- States: Opening, Open, Loading, Success/Error, Closing (CSS transitions).
- UX: centered flex container, backdrop overlay, Google Icon close button, focus trapping, close via Esc/overlay click.

## 4. Core UX & Micro-Interactions
- Responsive by default, fluid sizing, no horizontal overflow.
- CSS transitions on all state changes (`transition: var(--transition-normal)`), respecting `prefers-reduced-motion`.
- Accessibility: sufficient contrast both modes, never color-only state, semantic HTML5, ARIA roles/labels, logical focus order, full keyboard operability, `aria-live` for dynamic feedback.
- Mandatory visual feedback on every interaction.
- Destructive actions visually distinct in both themes.

## 6. Do's and Don'ts (enforce)
- Do: `#f2efe9` default canvas; `#1f1915` primary text; Geist 400 at 120px / 111.6px lh / -8px tracking for display hero; Fragment Mono 10px +0.3px for uppercase nav/labels/metadata; pill buttons `#ffffff`/`#fffdf6` with 1440px radius, `#1f1915` text, 12px vertical padding; 1px `#e6e3dd` dividers/frames; 16px radius cards/media, 8px inset images; reserve `#fa725a` for compact availability/upcoming-status text.
- Don't: no blue/green/purple accents (achromatic + `#fa725a` only); don't replace 1440px button radius; no drop shadows on `#ffffff`/`#fffdf6`/`#e6e3dd` cards; no bold large headings (Geist 400 display, Geist 500 subordinate); don't use pure `#ffffff` as broad page background when `#f2efe9` available; don't turn four-column grid into heavy bordered cards; don't use bright stock imagery (retain dark muted documentary treatment).

## 7. Elevation & Imagery
- Avoid cast shadows entirely. Hierarchy via `#f2efe9` → `#ffffff` → `#e6e3dd` progression, 1px `#e6e3dd` frames, translucent light overlays on dark photography, nested 8px/16px rounded media edges.
- Imagery: sparse but dominant; full-bleed darkened documentary photo of a maker; product screenshots as wide contained pale interfaces with soft 16px frames; Floating Film Teaser as only layered graphic. Icons tiny, mono black/muted graphite line marks.

## 8. Naming Convention
