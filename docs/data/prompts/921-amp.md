# Landing Page Prompt — "amp" Theme

Build a complete, responsive landing page for a fictional brand. **Never use the real brand name, logo, trademarks, or product names from the source spec** — invent a fictional brand name, product, and all copy. The visual style must strictly follow the "amp" design system described below.

## 1. Architecture & Rules

- **CSS-First, Zero Inline CSS:** All styling in `style.css`. No `style="..."` attributes. Class/ID selectors only. Clean semantic HTML.
- **CSS Variables:** Store all tokens in `:root` using the exact token names and values from the spec. Light-mode default. Dark mode is mandatory: provide dark tokens under `@media (prefers-color-scheme: dark)` and a `.dark` class. Persist user choice via `localStorage`, falling back to `prefers-color-scheme`; include a visible toggle with correct `aria-pressed`/`aria-label`.
- **Contrast Pairing:** Every light background token pairs with a dark text token and vice versa, in both themes.
- **Light Mode Background:** Use `#fefefe` where near-white is needed, not `#ffffff`.
- **Flexbox:** All layouts use `display: flex` with `align-items: center` by default. Mobile-responsive (rows collapse to columns), no horizontal scroll.
- **Tailwind CSS:** Use Tailwind (or `@layer`/`@apply` driven custom CSS). Utility classes map to CSS variables or reusable classes (`.btn`, `.card`, `.input-group`).
- **Typography & Icons:** Google Fonts only. Text: PublicaSans (substitute Inter if unavailable) via `<link>`/`@import`, bound to `--font-base`. Icons: Google Material Symbols/Icons. No inline SVGs or local icon files.
- **File Structure:** Separate `index.html`, `style.css`, `script.js`. Single deferred entry-point reference. One consistent class-naming convention (BEM) throughout.
- **No lorem-ipsum-only:** Use realistic fictional copy for all sections.

## 3. Component Specifications

### Primary Pill Button
Fill `--color-amp-orange`, white text, 50px radius, padding 16px vertical / 32px horizontal, PublicaSans 500 at 16px, letter-spacing -0.01em. Shadow `--shadow-md`. Optional trailing chevron icon (Material Symbols). Min touch target 44x44px. States: hover (brightness/shadow shift, cursor pointer), focus (distinct ring via CSS vars), active (scale 0.97), loading (spinner, disabled), disabled (opacity 0.5, greyscale, not-allowed), success/error (temporary feedback via `--text-success`/`--text-error`).

### Secondary Pill Button
Fill `#ffffff` or `#f3f4f3`, 1px border `#e5e5e5`, `#292b2a` text, 24px radius, padding 14px/24px, weight 400.

### Nav Buy Now Button
Fill `#ff6105`, white text, 40px radius, smaller scale. Mirrors primary pill at nav density.

### Step Indicator Row
Active step: orange pill badge "Step 1" white on `#ff6105`, weight 500 at 12px, 8px radius. Step title in Ink 18px weight 500 with 2px `#e5e5e5` underline. Inactive: "Step 2"/"Step 3" in Ash 12px, title in `#292b2a` 18px weight 400, underline 1px `#e5e5e5`.

### Press Logo Strip
Single row, 80-100px height, logos desaturated to Ink/Carbon, spacing 40-60px. Eyebrow "FEATURED ON" 12px tracked uppercase Ash.

### Editorial Section Heading
PublicaSans 300 at 48-72px, tracking -0.030 to -0.036em, color Ink. 2-3px `#ff6105` accent rule below at ~1/3 heading width.

### Dark Feature Band
Background `#202120` with 60-70% dark overlay over full-bleed product photo. White headline 48px weight 300, accent rule `#ff6105`. Padding 120px vertical.

### Featured Card (Peach)
Fill `#ffdfcd`, 5px radius, 16-20px padding, phone/product mockup right. Reserved for one card per section.

### Ghost Card
Fill `#ffffff`, 1px border `#e5e5e5`, 5px radius, 16-24px padding, no shadow. Image radius 8px. Heading 24px weight 500 Ink, body 16px weight 400 Carbon.

### Announcement Bar
Background Linen `#f3f4f3`, 40-48px height, centered text 14px weight 400 Carbon, right-side text link "Let's Go →" in Ink weight 500.

### Top Navigation
Background `#ffffff`, 64-72px height, logo left, 5 center links 14px weight 400 Carbon with 30-40px gaps, nav Buy Now button right. Optional 1px `#e5e5e5` bottom border.

### Input Field (Pill)
50px radius, 1px border `#e5e5e5`, 16px horizontal padding, PublicaSans 16px weight 400. Placeholder Ash. Focus ring 2px `#ff6105` at 40% opacity. States: empty, focused, filled, valid, invalid, disabled, read-only.

### Card (General)
Flexbox layout with subtle borders/elevation via `--bg-secondary` and CSS vars. Hover: elevation/shadow shift or `translateY(-2px)`. Focus-within: highlight border. Loading: shimmer skeleton. Empty state: Google Icon + guidance text.

### Modal/Popup
States: opening, open, loading, success/error, closing (CSS transitions). Centered flex container, backdrop overlay, Google Icon close button, focus trapping, close via Esc/overlay click.

## 4. UX & Micro-Interactions

- Responsive by default, fluid sizing, no horizontal overflow.
- CSS transitions on all state changes (`transition: var(--transition-normal)`), respect `prefers-reduced-motion`.
- Accessibility: sufficient contrast both themes, never color-only state communication, semantic HTML5, correct ARIA roles/labels, logical focus order, full keyboard operability, `aria-live` for dynamic feedback.
- Every click/hover/submission triggers visible state change.
- Destructive actions visually distinct in both themes.

## 5. Page Sections

Build these sections in order: Hero, Features (3 cards), How It Works (3 steps), Testimonials, Pricing (3 tiers), FAQ, Final CTA, Footer with secondary links.

- **Hero:** Full-viewport product image with single Buy Now CTA pill anchored bottom-center. Editorial headline 48-78px weight 300.
- **Features:** 3 Ghost Cards in flex row (collapse to column on mobile).
- **How It Works:** 2-column 50/50 — step list left (Step Indicator Row), phone mockup right.
- **Testimonials:** Card-based, Ghost Card style.
- **Pricing:** 3 tiers, Ghost Card style, primary CTA on recommended tier.
- **FAQ:** Accordion-style, CSS transitions.
- **Final CTA:** Editorial heading + accent rule + Primary Pill Button.
- **Footer:** Secondary links, Carbon text on white.

## 6. Do's and Don'ts

**Do:**
- Use `#ff6105` only for primary CTA fill, active step badge, accent rule, key brand strokes — never body text or large washes.
- Display headlines 48-78px weight 300, tracking -0.030 to -0.036em.
- Radius ladder: 5/8/24/32/50 defines hierarchy.
- Two-layer shadow only on primary CTA.
- Surface ladder: `#ffffff` → `#f3f4f3` → `#e5e7eb` → `#ffdfcd` → `#202120`.
- Body copy PublicaSans 16px weight 400, line-height 1.5, -0.01em tracking; weight 500 for buttons, step titles, short labels.
- 2-3px `#ff6105` accent rule beneath editorial headlines at ~1/3 width.

**Don't:**
- No second accent color.
- No weight 600/700 — max 500.
- No shadows on cards, images, or non-primary buttons.
- No 50px radius except primary CTA and inputs.
- No all-caps or positive letter-spacing on display text.
- No large `#ff6105` fills.
- No mixing rounded/square corner systems.
