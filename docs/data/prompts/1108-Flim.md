# Coding AI Prompt — Landing Page in "Flim" Style

You are a senior frontend engineer. Build a complete, responsive landing page as separate `index.html`, `style.css`, and `script.js` files. Do **not** use inline `style="..."` attributes anywhere. All styling must live in `style.css` via class/ID selectors. Use Tailwind CSS (via CDN) only as a utility layer that maps back to CSS variables and reusable class names (`.btn`, `.card`, `.input-group`); the canonical tokens must be defined in `:root` CSS variables.

## 1. Brand & Copy Rules
- **Invent a fictional brand name, product, and all copy.** Never use "Flim", its logo, trademarks, or product names. Treat the supplied spec as a visual style reference only.
- All user-facing copy must be in English.
- No lorem-ipsum-only submissions where real copy is expected; placeholders are allowed only where content is genuinely unspecified.

## 2. Theme Tokens (`:root` + `.dark`)
Define these CSS variables in `:root` (light) and override under `@media (prefers-color-scheme: dark)` and `.dark`:

- Colors: `--color-ink: #141414`, `--color-paper: #ffffff`, `--color-canvas: #f5f5f5`, `--color-mist: #e9e9e9`, `--color-hairline: #d9d9d9`, `--color-signal-green: #30a81d`, `--color-forest: #21935b`, `--color-highlight-yellow: #fecc33`, `--color-ember: #ff8400`.
- Map to generic tokens: `--primary: var(--color-ink)`, `--secondary: var(--color-mist)`, `--bg-primary: var(--color-canvas)`, `--bg-secondary: var(--color-paper)`, `--text-primary: var(--color-ink)`, `--text-secondary: var(--color-ink)`, `--text-success: var(--color-signal-green)`, `--text-error: var(--color-ember)`, `--border-default: var(--color-hairline)`, `--border-error: var(--color-ember)`, `--border-success: var(--color-signal-green)`.
- Radii: `--radius-sm: 4px`, `--radius-md: 8px`, `--radius-lg: 16px`, plus `--radius-pill: 160px`.
- Shadows: `--shadow-sm`, `--shadow-md` defined but **never applied** (this system uses no drop shadows).
- Spacing: `--spacing-gap: 24px`, `--spacing-4/8/12/16/20/24/28/32/40/52/64/80/100/180` per spec.
- Transitions: `--transition-fast`, `--transition-normal`, `--ease-standard`.
- Z-index: `--z-dropdown`, `--z-modal`, `--z-toast`.
- Fonts: `--font-base` (Arial/system-ui), `--font-display` (Swizzy substitute: Druk Wide / Migra / Schibsted Grotesk at weight 500), `--font-mono` (PP Neue Montreal Mono substitute: JetBrains Mono / IBM Plex Mono / Space Mono at 400 with 0.06em tracking).

Enforce contrast pairing in both light and dark modes. Light mode background must not be pure white; use `#f5f5f5` canvas. Where near-white is needed use `#fefefe`.

## 3. Dark Mode (Mandatory)
- Provide dark tokens under `@media (prefers-color-scheme: dark)` and `.dark`.
- Persist user choice via `localStorage`, falling back to `prefers-color-scheme` on first visit.
- Include a visible toggle control with correct `aria-pressed`/`aria-label`.

## 4. Typography (Google Fonts Mandatory)
- Load Google Fonts via `<link>`/`@import`: Schibsted Grotesk (display substitute), JetBrains Mono (mono substitute), and Inter (body substitute). Bind to CSS variables.
- Use Google Material Symbols for icons. No raw inline SVGs or local icon files.

## 5. Layout Rules
- Flexbox (`display: flex`) for all layout; default `align-items: center` unless explicitly justified.
- Mobile-first, responsive, no horizontal scroll.
- Full-bleed page, no max-width container. 80px+ section gaps.
- Grid background: repeating `#d9d9d9` 1px lines on `#f5f5f5` canvas at ~32-40px intervals via repeating linear-gradient. This is a visual texture, not a layout grid.

**Hero:** Split layout — oversized wordmark left (display font 125px, weight 500, `#141414`, letter-spacing -2.5px, line-height 0.86), right-aligned tagline block right (Arial 32px, line-height 1.13). Both on canvas with grid pattern.

**Ghost Nav Links:** Mono 12px, `#141414`, 0.72px tracking, uppercase, no bg/border, padding 6px 0. Items: HOME, PRICING, LOG-IN, SIGN-UP.

**Filled Action Button:** `#141414` bg, `#ffffff` text, 8px radius, ~20px horizontal / ~8px vertical padding, mono 12px, 0.72px tracking. Only filled button in system.

**Image Thumbnail Card:** 16px radius, 1px `#d9d9d9` border, no shadow/padding. Varying widths 150-350px, asymmetric scattered arrangement. No drop shadows anywhere.
