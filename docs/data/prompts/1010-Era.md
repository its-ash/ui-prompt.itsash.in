# Landing Page Build Prompt — "Era" Editorial Theme (Fictional Brand)

You are a senior front-end engineer. Build a complete, production-ready landing page for a **fictional** fintech/financial-product brand (invent your own brand name, product name, and all copy — never use "Era", "Claude", "Thesis", "Context", "Agency", or any real trademark/product name from the reference). The page must strictly follow the design system below.

## 1. Architecture & Global Rules

**1.1 CSS-First, Zero Inline CSS**
- All styling lives in `style.css`. No `style="..."` attributes in HTML.
- Target elements via class/ID selectors only. Keep HTML semantic and styling-agnostic.
- File structure: `index.html`, `style.css`, `script.js`. No inline `<script>` blocks beyond a single deferred entry-point reference.

**1.2 CSS Variables & Theme Tokens**
Define all tokens in `:root` and a `.dark` class / `@media (prefers-color-scheme: dark)` block. Required tokens:

Colors (light defaults):
- `--color-ink: #191a17` (primary text, filled CTA bg, nav links, icon strokes, card borders)
- `--color-parchment: #f3f3f1` (page canvas)
- `--color-ash: #e6e6e4` (hairline borders, dividers, footer borders)
- `--color-paper: #ffffff` (light neutral action fill on dark surfaces)
- `--color-smoke: #868784` (secondary text, link underlines, muted copy)
- `--color-charcoal: #3d3d3d` (dark badge backgrounds)
- `--color-sage-wash: #add2d1` (product feature card bg — teal panel)
- `--color-slate-teal: #9dbebe` (secondary product card bg)
- `--color-dusk-gradient: linear-gradient(90deg, rgb(201,197,225) 0%, rgb(234,211,221) 100%)` (decorative accent)

Map to generic tokens: `--primary`, `--secondary`, `--bg-primary`, `--bg-secondary`, `--text-primary`, `--text-secondary`, `--text-success`, `--text-error`, `--border-default`, `--border-error`, `--border-success`.

Contrast pairing: every light bg token pairs with a dark text token and vice versa in both themes. Light mode page bg is `#f3f3f1` (Parchment), never pure white; use `#fefefe` only where near-white is genuinely needed.

Radius/shadows: `--radius-sm: 6px`, `--radius-md: 12px`, `--radius-lg: 9999px`, `--shadow-sm: none`, `--shadow-md: none` (zero shadows — flat system).

Spacing/transitions: `--spacing-gap: 16px`, `--transition-fast`, `--transition-normal`, `--ease-standard`. Elevation/stacking: `--z-dropdown`, `--z-modal`, `--z-toast`.

Typography tokens: `--font-base` bound to Inter (Google Font, substitute for the custom Saans VF). OpenType features `"lnum" on, "tnum" on` on all numeric content. Letter-spacing: `-0.02em` at 30px+, `-0.01em` at 20px and below. Type scale tokens: `--text-caption: 12px`, `--text-body-lg: 16px`, `--text-subheading: 20px`, `--text-heading-sm: 30px`, `--text-heading: 35px`, `--text-display: 56px`.

Spacing scale: `--spacing-8: 8px`, `--spacing-16: 16px`, `--spacing-24: 24px`, `--spacing-32: 32px`, `--spacing-40: 40px`, `--spacing-48: 48px`. Page max-width 1200px, section gap 80px, card padding 24px, element gap 16px.

**1.3 Mandatory Dark Mode**
- Provide dark tokens under `@media (prefers-color-scheme: dark)` and `.dark` class.
- In dark mode: page bg becomes a warm dark (e.g. `#1a1a18`), text becomes light, product cards invert appropriately, borders remain subtle. Maintain contrast pairing.
- Theme choice persists via `localStorage`, falling back to `prefers-color-scheme` on first visit. Include a visible toggle with correct `aria-pressed`/`aria-label`.

**1.4 Flexbox & Mobile-First**
- All layouts use Flexbox. Every flex container defaults to `align-items: center` unless explicitly justified.
- Mobile-responsive: rows collapse to columns on small viewports. No horizontal scrolling.

**1.5 Framework**
- Use Tailwind CSS (or clean custom CSS via `@layer`/`@apply`) mapping utilities to CSS variables and reusable classes (`.btn`, `.card`, `.input-group`). Never mix naming conventions — use BEM consistently.

**1.6 Typography & Icons**
- Google Font: Inter (weights 300–700) via `<link>`/`@import`, bound to `--font-base`.
- Icons: Google Material Symbols only. No inline SVGs or local icon files.

## 2. Component Specifications

**2.1 Buttons**
- Default: flex, `align-items: center`, `justify-content: center`, `gap: 0.5rem`, min touch target 44x44px.
- Primary CTA (filled pill): bg `--color-ink`, text `--color-paper`, radius 9999px, padding 8px 16px, font weight 500 at 15px, letter-spacing -0.01em. No border, no shadow.
- Outlined (ghost pill): bg `--color-paper`, 1px solid `--color-ink`, radius 9999px, padding 8px 16px, font weight 500 at 15px, color ink. Optional leading icon (16px, 8px gap).
- Hover: slight lightness shift + cursor pointer. Focus: distinct focus ring via CSS vars. Active: `transform: scale(0.97)`. Loading: disabled, spinner (CSS or animated Material Icon), no dimension change. Disabled: opacity 0.5, greyscale, cursor not-allowed. Success/Error: temporary styles via `--text-success`/`--text-error`.

**2.2 Cards**
- Default: flex layout, subtle borders, elevation via surface color only (no shadows), radius 12px, padding 24px.
- Hover: subtle `transform: translateY(-2px)` (no shadow). Focus-within: highlight border. Loading (skeleton): shimmer CSS animation, no layout jump. Empty state: Material Icon + guidance text.

**2.3 Product Feature Cards (3 variants)**
- Context (lavender): radius 12px, bg `--color-dusk-gradient`, padding 24px. Badge "Personal MCP" (radius 6px, light fill, ink text) top-right. Heading: weight 380 at 30px, ink. Body: weight 400 at 15px, ink. Product screenshot anchored bottom-right, partially overflowing card edge.
- Agency (dark inverted): radius 12px, bg `--color-ink`, padding 24px. Badge "Native app" (radius 6px, ash/white fill, ink text) top-right. Heading: weight 380 at 30px, paper. Body: weight 400 at 15px, paper.
- Thesis (sage): radius 12px, bg `--color-sage-wash`, padding 24px. All text ink. Softest surface.

**2.4 FAQ Accordion**
- Full-width row, 1px bottom border `--color-ash`. Question: weight 500 at 15px, ink. Plus/minus icon (ink) right-aligned, 16px. Expanded answer: weight 400 at 15px, smoke, 16px top/bottom padding. Animate open/close via CSS transitions.

**2.5 Product Badge/Tag**
- Radius 6px, bg ash or paper, ink text, ~8px horizontal / ~4px vertical padding, weight 500 at 12px. Optional leading ✦ diamond icon (ink, ~12px).

**2.6 Partner Logo Strip**
- Single horizontal row, centered, ~48px gap. All logos desaturated to smoke (`--color-smoke`). No full-color logos.

**2.7 Section Heading**
- Weight 380 at 35px, ink, letter-spacing -0.02em, line-height 1.20. Left-aligned. No decoration.

**2.8 Hero Headline**
- Weight 380 at 56px, ink, letter-spacing -0.02em (≈ -1.12px), line-height 1.15. On parchment canvas. No underline/decoration.

**2.9 Footer**
- 1px top border ash, 48px vertical padding. Weight 400 at 13px, smoke links. Monochrome only.

**2.10 Decorative Diamond Icon (✦)**
- Four-point diamond in ink, ~12px, used as visual bullet before section labels and inside badges.

**2.11 Forms & Inputs**
- States: empty, focused (outline ring), filled, valid (success border/icon), invalid (error border, red text, error icon), disabled, read-only. Flex container wrapping label, input, error feedback.

**2.12 Modal/Popup**
- States: opening, open, loading, success/error, closing (CSS transitions). Centered flex (`align-items: center`), backdrop overlay, Material Icon close button, focus trapping, close via Esc/overlay click.

## 3. Core UX & Micro-Interactions

- Responsive by default; fluid sizing; no horizontal overflow.
- CSS transitions on all state changes (`transition: var(--transition-normal)`); respect `prefers-reduced-motion`.
- Accessibility: sufficient contrast in both themes; never rely on color alone; semantic HTML5; correct ARIA roles/labels; logical focus order; full keyboard operability; `aria-live` regions for dynamic feedback.
- Mandatory visual feedback on every click/hover/submission.
- Destructive actions visually distinct in both themes.
- Zero shadows anywhere (flat system). Elevation via surface color contrast only.

1. **Nav** — minimal top bar: wordmark left, links (Pricing, Company, Articles) + Sign in + filled CTA right.

9. **Final CTA** — centered headline + filled pill button on parchment (or ink panel).
10. **Footer** — links, 1px top border ash, 48px vertical padding, smoke links.
