# Coding-AI Prompt: Complete Landing Page — "Arc" Theme

## 1. Project Overview

Build a complete, responsive landing page for a fictional brand (invent a fictional name, product, and copy — never use the real brand name "Arc", its logo, trademarks, or product names). The visual style is an industrial white gallery suspended above dark ocean: monastic white space, full-bleed aerial marine photography, a single deep teal-navy band as rhythmic counterpoint, skeletal components with thin ghost buttons, 5px corner radii on controls, 32px radii on imagery, almost no shadow, and generous negative space. The Soehne family (substitute: Inter) carries a weight-300 display voice at 48–140px; body text at 16–18px weight 400 with tight tracking. Color is 99% achromatic plus two near-black teals; no chromatic accent.

**Sections required:** Hero, Features (3 cards), How It Works (3 steps), Testimonials, Pricing (3 tiers), FAQ, Final CTA, Footer with secondary links.

## 2. Mandatory Architecture Rules

### 2.1 CSS-First, Zero Inline CSS
- Keep all styling in `style.css`. Forbid `style="..."` attributes in HTML.
- Target via class/ID selectors only. Keep HTML semantic, clean, and styling-agnostic.
- Changing the look must require editing only CSS, not markup.

### 2.2 CSS Variables & Theme Tokens
Define all tokens in `:root` and theme classes using CSS variables:

**Colors:**
- `--color-bone: #e5e7eb` (page canvas, card surfaces, hairline dividers, ghost-button borders)
- `--color-charcoal: #0a0a0a` (primary body/heading text, nav links, footer text, filled button text)
- `--color-paper: #ffffff` (card surfaces, filled button backgrounds, image overlays, reverse text on dark sections)
- `--color-obsidian: #000000` (headings on light canvas where max contrast needed; used sparingly)
- `--color-deep-current: #031e25` (dark feature section backgrounds, large image containers)
- `--color-slate-depth: #1d1d1e` (secondary dark section background, elevated panels)

**Contrast pairing:** light backgrounds pair with dark text; dark backgrounds pair with light text in every theme.

**Light mode background:** use `#e5e7eb` (bone) as canvas, not pure white. Where near-white is needed, use `#fefefe` instead of `#ffffff`.

**Border radius & shadows:**
- `--radius-control: 5px` (buttons, inputs)
- `--radius-image: 32px` (imagery)
- `--radius-nav: 2.25px`
- `--radius-card: 0px`
- `--shadow-md: rgba(0, 0, 0, 0.05) 0px 10px 15px -3px` (isolated hero use only)

**Spacing & transitions:**
- `--spacing-gap: 18px` (element gap)
- `--transition-fast: 0–150ms` (near-instant; no bounce/ease-out)
- `--transition-normal: 150ms`
- `--ease-standard: linear` (motion is near-static)

**Elevation/stacking:** `--z-dropdown`, `--z-modal`, `--z-toast`.

### 2.3 Mandatory Dark Mode
- Provide dark mode tokens under `@media (prefers-color-scheme: dark)` and/or `.dark` class.
- Background and text variables switch seamlessly without HTML restructuring.
- Persist user theme choice via `localStorage`, falling back to `prefers-color-scheme` on first visit.
- Visible toggle control with correct `aria-pressed`/`aria-label`.

### 2.4 Flexbox Layout & Mobile-First
- Use Flexbox (`display: flex`) for all layouts.
- Every flex container defaults to `align-items: center` unless explicitly justified.
- Mobile-responsive out of the box (rows → columns on small viewports). No horizontal scrolling.

### 2.5 Framework
- Use Tailwind CSS (or clean custom CSS via `@layer`/`@apply`). Utility classes map to CSS variables or generic reusable classes (`.btn`, `.card`, `.input-group`).

### 2.6 Typography & Icons
- Google Fonts mandatory. Text: Inter (substitute for Soehne) via `<link>`/`@import`, bound to `--font-base`.
- Icons: Google Material Symbols/Icons only. Forbid raw inline SVGs or local icon files.

## 3. Typography Tokens

- Font family: Inter (weights 300, 400, 500, 600). OpenType features `"ss01" on, "tnum" on`.
- Type scale tokens:
  - `--text-caption: 11px` (line-height 1.3, letter-spacing +0.185em, uppercase labels)
  - `--text-body-sm: 14px` (line-height 1.44)
  - `--text-body: 16px` (line-height 1.44)
  - `--text-body-lg: 18px` (line-height 1.44, letter-spacing -0.01em)
  - `--text-subheading: 22px` (line-height 1.33, letter-spacing -0.012em)
  - `--text-heading: 32px` (line-height 1.3, letter-spacing -0.016em)
  - `--text-heading-lg: 48px` (line-height 1.16, letter-spacing -0.021em)
  - `--text-display: 140px` (line-height 1.0, letter-spacing -0.043em)
- Display headings: 48–140px, weight 300, tracking -0.021em to -0.043em.
- Body/subheadings: weight 400. Nav/meta: weight 500. Button labels: weight 600.
- Uppercase +0.15em–0.185em tracking only for labels, meta, nav, button text. Never for body or headings.
- Body text range: 14–18px only. Never above 18px or below 14px.

## 4. Spacing Tokens

- `--spacing-4: 4px`, `--spacing-5: 5px`, `--spacing-6: 6px`, `--spacing-9: 9px`, `--spacing-10: 10px`, `--spacing-14: 14px`, `--spacing-18: 18px`, `--spacing-20: 20px`, `--spacing-30: 30px`, `--spacing-36: 36px`, `--spacing-45: 45px`, `--spacing-72: 72px`, `--spacing-80: 80px`, `--spacing-81: 81px`, `--spacing-100: 100px`, `--spacing-215: 215px`.
- Page max-width: 1200px. Section gap: 36–64px. Card padding: 20px. Element gap: 18–20px.

## 5. Component Specifications

### 5.1 Buttons
- **Ghost nav button:** transparent bg, `#0a0a0a` text, 12–14px weight 500, +0.15em uppercase, no border/fill. Underline or weight shift on hover. 45px horizontal padding in nav.
- **Outlined CTA:** transparent or `#ffffff` fill, 1px `#0a0a0a`/`#ffffff` border, 5px radius, 20px vertical × 20px horizontal padding, 11–12px weight 500 uppercase +0.15em. Text color matches border (reversible on dark sections). Min touch target 44×44px.
- **Filled reversed:** `#ffffff` fill on `#031e25` bg, `#0a0a0a` text, 5px radius, same padding/tracking. Used sparingly.
- **States (all buttons):** default, hover (brightness/shadow shift, cursor pointer), focus (distinct focus ring via CSS vars), active (scale 0.97), loading (disabled interactions, CSS spinner/animated Google Icon, no dimension distortion), disabled (opacity 0.5, greyscale, cursor not-allowed), success/error (temporary feedback via `--text-success`/`--text-error`).

### 5.2 Cards
- **Feature card:** `#031e25` bg, 32px-radius image at top (100% width), 20px padding, white weight-400 16px body, white weight-400 22px heading. No border, no shadow.
- **States:** default, hover (elevation/shadow shift or translateY -2px), focus-within (border highlight), loading (skeleton shimmer in CSS), empty state (Google Icon + guidance text).

### 5.3 Forms & Inputs
- States: empty, focused (outline ring), filled, valid (success border/icon), invalid (error border, red text, error icon), disabled, read-only.
- Structure: flex container wrapping label, input, dedicated error feedback container.

### 5.4 Modal/Popup
- States: opening, open, loading, success/error, closing (CSS transitions).
- Centered flex container, backdrop overlay, Google Icon close button, keyboard focus trapping, close via Esc or overlay click.

### 5.5 Other Components
- **Hero image container:** 100vw × 100vh, object-fit cover, text overlay bottom-left ~40px from edges. No radius, no border.
- **Centered statement block:** full-width `#ffffff` or `#e5e7eb` band, max-width 720px centered, 32–48px weight-300 heading tight tracking, 48–64px vertical padding. Statement alone.
- **Hairline divider:** 1px `#e5e7eb` line, full or column width.
- **Logo mark:** lowercase wordmark, weight 300, 32–48px, `#ffffff` on dark / `#0a0a0a` on light, tracking -0.021em.
- **Overlay image frame:** 32px radius, contained in max-width column, no border/shadow.
- **Footer link row:** 12px weight 400–500, +0.15em uppercase, 20px horizontal gap, no dividers/bullets.
- **Hamburger trigger:** two stacked 1px `#0a0a0a` lines, 18px wide, 2.25px radius. No bg, no animation chrome.
- **Meta label:** 11px weight 500 uppercase, +0.185em tracking, `#0a0a0a`, prefixed with small flag/icon mark.
- **Card grid container:** equal columns, 18–20px column gap, 36px row gap, no visible grid lines.

## 6. Section Rhythm & Layout

- Alternate: dark photo hero → white statement → dark feature grid → light detail blocks.
- Navigation: minimal top bar, logo-left, links-center, hamburger-right, transparent over hero.
- Spacing: 36–64px between sections, 18–20px between elements, 20px inside cards.
- No sidebar, mega-menu, or sticky behavior.
- Full-bleed for hero/feature imagery; max-width 1200px contained for text/grids.

## 7. Core UX & Micro-Interactions

- Responsive by default, fluid sizing, no horizontal overflow.
- Transitions: 0–150ms, no bounce/ease-out, no scroll-triggered reveals, no parallax (motion profile is "none"/stillness).
- Accessibility: sufficient contrast both modes, never rely on color alone, semantic HTML5, correct ARIA roles/labels, logical focus order, full keyboard operability, `aria-live` for dynamic feedback.
- Mandatory visual feedback on every click/hover/submission.
- Destructive actions visually distinct in both themes.
- Respect `prefers-reduced-motion`.

## 8. Do's and Don'ts

**Do:** only Soehne/Inter at 300/400/500/600; display 48–140px weight 300 tracking -0.021 to -0.043em; 5px controls / 32px images; alternate `#e5e7eb`/`#ffffff` light bands with `#1d1d1e`/`#031e25` dark bands; uppercase tracking only for labels/meta/nav/buttons; let aerial marine photography carry visual weight; `#e5e7eb` 1px hairlines.

**Don't:** no chromatic accent; no weight ≥700; no drop shadows/glows/blur beyond single hero shadow; no radius 6–31px; no text on photo without overlay/card; no centered body copy >2 lines; no illustrations/icons-as-decoration/3D renders; body 14–18px only.

## 9. Imagery

Marine, aerial/high-angle photography. Full-bleed or 32px-radius framed. Naturalistic color (deep teal-green water carries chromatic energy). No illustration, iconography beyond smallest utility glyphs, 3D renders, abstract graphics. Boats shown in motion from above. Software screenshots as flat product evidence in feature cards. Image-dominant in hero/feature; text-dominant in transitions/detail.

## 10. Deliverables

- Separate `index.html`, `style.css`, `script.js`. No inline `<script>` beyond single deferred entry-point reference.
- Consistent class-naming convention (BEM or fixed utility set) throughout — never mix.
- No lorem-ipsum-only submissions where real copy/labels supplied; placeholders only where content genuinely unspecified.
- Invent fictional brand name, product, and copy. Never use real brand name, logo, trademarks, or product names.

## 11. Animation Philosophy

Static, almost motionless. If animation needed: instant or near-instant (0–150ms), no bounce/ease-out, no scroll-triggered reveals, no parallax. Stillness is part of engineering aesthetic.

## 12. Output

Output only the finished code files (`index.html`, `style.css`, `script.js`) with no preamble or closing commentary. Ensure all mandatory rules above are satisfied. All user-facing copy in English. All CSS variable names, class names, file names in English/ASCII.
