    helpWhat hardware do I need?

    Nimbus runs on any Amiga 500 or better with Kickstart 1.3+. For optimal performance, we recommend 2MB RAM and a hard drive, but it works flawlessly with floppy-only setups.

    helpIs this compatible with emulators?

    Absolutely! Nimbus has been tested in WinUAE, FS-UAE, and MiSTer. Simply mount the provided ADF file as a floppy disk and boot as usual.

    helpCan I upgrade my tier later?

    Yes! Contact support with your current license key and we'll provide a prorated upgrade path to any higher tier at any time.

    helpWhat about software compatibility?

    Nimbus maintains full backward compatibility with existing Amiga software. Run your favorite games, demos, and productivity tools without modification.
