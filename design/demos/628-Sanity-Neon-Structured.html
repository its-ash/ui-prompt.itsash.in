05, FAQ

Frequently asked questions

What is structured content?expand_more

Structured content is stored as typed data fields rather than formatted pages. A product, article, or event becomes a document with defined fields, so the same content can render on a website, an app, or a voice interface without copy-paste.

Can I migrate from my current CMS?expand_more

Yes. Strukt ships with importers for WordPress, Contentful, and plain JSON or CSV. Most teams map their existing content types to Strukt schemas and run a scripted migration in days, not months.

How does real-time collaboration work?expand_more

Every document is synced through a conflict-free replicated data layer. Editors see live cursors and field-level presence, and simultaneous edits merge automatically without locking documents.

What query languages do you support?expand_more

Strukt supports GROQ, a declarative query language built for JSON content, and a generated GraphQL endpoint derived from your schemas. Both are served from a global CDN with cached, sub-100ms reads.

Is there an on-premise or EU hosting option?expand_more

Scale plans can pin data residency to EU regions, and enterprise agreements include dedicated infrastructure options. Contact sales for compliance documentation including SOC 2 and GDPR commitments.

What happens if I exceed my API limit?expand_more

Nothing breaks. We notify you at 80% and 100% of your quota, and overage is billed at a published per-request rate. Free projects are rate-limited gracefully rather than taken offline.
