How does the whiteboard work?
Nimbus provides an infinite canvas where you can draw, add sticky notes, import images, and collaborate in real time with teammates.
Can I use it offline?
Yes, you can edit boards offline and changes sync when you’re back online.
Is my data secure?
All boards are encrypted at rest and in transit. You control who can view or edit each board.
