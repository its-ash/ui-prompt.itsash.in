Frequently Asked Questions

What is Nimbus?
Nimbus is an open‑source infrastructure as code software tool that provides a consistent CLI workflow to manage hundreds of cloud services.
How does Nimbus differ from other IaC tools?
It uses a declarative language, state management, and a plugin‑based provider system that supports any cloud or on‑premises infrastructure.
Is Nimbus free to use?
Yes. The core CLI is open source under the MPL 2.0 license. Paid tiers add collaboration, governance, and support features.
