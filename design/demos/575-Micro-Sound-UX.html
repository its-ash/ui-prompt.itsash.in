Common questions

Will sounds autoplay without user consent?expand_more

No. The audio context initializes lazily on the first genuine user gesture, which satisfies Chrome, Safari and Firefox autoplay policies. Before that, all feedback is purely visual.

Can users mute everything permanently?expand_more

Yes. The floating mute toggle gates all sound output and persists the choice in local storage. Visual cues like ripples and glows remain active so feedback is never lost.

Does it work with screen readers and reduced motion?expand_more

Every sound has a visual equivalent, state changes are announced through an aria-live region, and shake, ripple and glow animations are disabled when the user prefers reduced motion.
