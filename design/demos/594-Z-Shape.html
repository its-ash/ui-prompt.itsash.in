FAQ

Quick answers

Does it slow down my app?expand_more

The script loads after your app and weighs 18 KB. Flows render only when a user qualifies for one.

Do I need engineers to build flows?expand_more

No. Anyone can build and publish flows in the visual editor. Engineers only install the snippet once.

Can flows differ by user role?expand_more

Yes. Target flows by role, plan, country or any property you send us.

Is my user data safe?expand_more

We are SOC 2 Type II certified and store data in the EU or US, your choice.
