Questions, answered

Do you store my recordings?expand_more

No. Audio is transcribed on the fly and discarded immediately. Only the transcripts you choose to save are kept — encrypted at rest and in transit.

Which languages does Voxa understand?expand_more

Voxa speaks and understands 32 languages today, with real-time translation between them on Pro and Enterprise plans.

Can Voxa run offline or on-premises?expand_more

Yes. Enterprise deployments run in a private cloud or fully on-premises, using the same voice models with zero external calls.

Is it accessible to screen reader users?expand_more

Voxa targets WCAG 2.1 AA: every voice state is announced, every control is keyboard-operable, and nothing is conveyed by color alone.
