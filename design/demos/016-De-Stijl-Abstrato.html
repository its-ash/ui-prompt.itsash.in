FAQ

Is NEOGRID a component library or a design system?expand_more

Both. It ships as one token file plus 40 layout primitives, from cards to full-page scaffolds. Reskin an entire product by editing tokens — never the markup.

Can I use my own colors?expand_more

You can swap the token file, but NEOGRID is opinionated by design: red, blue, yellow, black, and off-white only. The constraint is the feature.

Do exports include dark mode?expand_more

Yes. Every export ships both themes behind a single class toggle, with line colors flipped and contrast pairings verified before build.
