Frequently Asked Questions

How does real-time data collection work? expand_more

Nimbus uses lightweight agents that push metrics via efficient binary protocols. Data is streamed to our processing engine with sub-second latency, enabling real-time dashboards and instant alerting.

What is the performance impact on my systems? expand_more

Our agents are designed for minimal overhead: typically <2% CPU and <10MB RAM per instance. We use adaptive sampling to reduce load during high-activity periods.

Can I monitor cloud services like AWS or Azure? expand_more

Yes! We offer native integrations for AWS CloudWatch, Azure Monitor, GCP Operations, and popular SaaS platforms like Kubernetes, Docker, and MongoDB.

How secure is my data in Nimbus? expand_more

All data is encrypted in transit (TLS 1.3) and at rest (AES-256). We are SOC 2 Type II certified and offer granular role-based access controls with detailed audit logs.

What happens if my internet connection drops? expand_more

Agents cache data locally and automatically resync when connectivity is restored. You won't lose any data, and alerting rules continue to evaluate against cached values.
