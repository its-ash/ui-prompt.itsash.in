Frequently Asked Questions

What is Wabi‑Sabi Anti‑UX?

It’s a design philosophy that embraces imperfection, natural textures, and intentional friction to create more human digital experiences.

Do I need to install anything?

No. Nimbus generates a single HTML file you can host anywhere—no build step, no dependencies.

Can I use my own photos?

Absolutely. Replace the placeholder images with your own; we recommend desaturating and adding a slight rotation for the best effect.
