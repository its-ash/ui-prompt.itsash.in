Frequently asked questions

How many integrations does Composio support?expand_more

Over 250 managed integrations, including GitHub, Slack, Linear, Notion, Gmail, and Salesforce. New apps ship weekly, and every integration follows the same tool schema so your agent code never changes.

How is authentication handled for end users?expand_more

Composio brokers OAuth per user with least-privilege scopes. Tokens are encrypted at rest, refreshed automatically, and never exposed to the model or your application code.

Which SDK languages are available?expand_more

First-class SDKs for Python and TypeScript, with plugins for OpenAI, Anthropic, LangChain, LlamaIndex, and CrewAI. A REST API covers everything else.

What happens when a tool call fails?expand_more

Failed calls are retried with backoff, rate limits are respected per provider, and every attempt appears in the trace log with the full request and response payload.

Can I self-host Composio?expand_more

Yes. The Enterprise tier includes VPC and on-prem deployment options with SSO, audit logging, and a dedicated support engineer for rollout.
