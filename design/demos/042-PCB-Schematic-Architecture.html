Frequently asked questions

Can I import an existing KiCad or Altium project?expand_more

Yes. TraceWorks imports KiCad, Altium, and Eagle schematics with 98%+ net fidelity — and you can export back out at any time.

Does the free Prototype tier expire?expand_more

Never. Three private projects, full ERC, and the community library stay free. Upgrade only when you need the constraint engine.

How does version control handle merges?expand_more

Every save is a commit. Conflicts resolve net-by-net in a visual diff, so two engineers can branch and merge a schematic like code.
