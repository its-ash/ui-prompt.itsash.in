How does the glyph rain animate?
The cascade is pure CSS keyframes translating monospace characters down each column. No canvas, no SVG — just text with backdrop blur.
Can I use it in dark mode?
Yes — the whole theme swaps via a single class on <html>. Rain opacity inverts for readability.
Is it accessible with screen readers?
The rain is decorative (aria‑hidden). All interactive elements use proper ARIA, focus rings, and keyboard navigation.
