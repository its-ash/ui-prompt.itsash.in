Frequently Asked Questions

What is Nimbus?
Nimbus is a Web3 compute platform built on the EOS blockchain, offering high‑throughput smart contract execution with low latency and developer‑friendly tooling.
Do I need to hold EOS tokens?
Yes. To execute contracts you stake EOS for CPU, NET, and RAM resources. Staking also earns you network rewards.
Is my data private?
All contract code and state are stored on‑chain. Private data can be encrypted off‑chain and referenced via hashes.
