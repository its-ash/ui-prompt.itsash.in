How does the drawing animation work?

The scene is built with CSS keyframes that stroke‑reveal each vector path in sequence. No canvas or JS rendering is involved — pure stylesheet choreography.

Can I export the scene as SVG?

Yes. The entire savanna is constructed from vector‑compatible CSS shapes and gradients, so the final markup can be exported as clean SVG.

Is my data stored?

No. WILDLINE runs entirely client‑side. No scene data leaves your browser.
