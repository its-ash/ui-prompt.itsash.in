Frequently Asked Questions

Answers to common questions about Nimbus.

How does Nimbus integrate with my existing CI/CD pipeline?
Nimbus provides a GitHub Action that runs as a step in your workflow. It analyzes your code and posts review comments directly on pull requests.
What programming languages does Nimbus support?
Nimbus supports all major languages including JavaScript/TypeScript, Python, Java, Go, Ruby, PHP, and C/C++. Language-specific rules are available via community plugins.
Is my code secure and private?
Yes. Nimbus processes code in ephemeral containers and never stores your source code. All analysis happens in your GitHub-hosted runners or self-hosted infrastructure.
Can I customize the review rules?
Absolutely. Configure rules via a .nimbusrc file in your repository or use the UI to set thresholds for severity, file patterns, and more.
What happens if I exceed my repository limit?
On the Free plan, additional repositories will be skipped until you upgrade. Paid plans include unlimited repositories.
