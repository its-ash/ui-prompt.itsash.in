Common questions

Does Nimbus store my source code?expand_more
Nimbus processes code in memory to build its analysis index and never retains full source files. Enterprise plans can run entirely inside your own infrastructure.
Which languages are supported?expand_more
TypeScript, JavaScript, Python, Go, Rust, Java, and Ruby are fully supported today, with Kotlin and C# in public beta.

Yes. The Starter plan is free forever, and every paid plan begins with a 14-day trial. No credit card is required to start.
