Common questions

Short answers before you start.

Can I import my existing design tokens?expand_more

Yes. Nimbus accepts JSON and CSS variable files, then maps them onto your project grid and component library automatically.

Does Nimbus work for print projects?expand_more

It does. Exports include CMYK-ready PDF and color separations tuned for risograph and screen printing workflows.

What happens when my trial ends?expand_more

Your projects stay readable forever. You keep full export access on the free Studio plan and can upgrade whenever you need more.
