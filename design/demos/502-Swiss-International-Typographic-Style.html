How it works

A fixed sequence. No improvisation required.

01

Define the grid

Set columns, gutters, and margins for your project. GRID generates the underlying structure and stores it as a reusable system.

02

Place the content

Drop text, images, and components onto the grid. Alignment is automatic. Every element reports its position and span.

03

Export the system

Publish production-ready CSS with one action. Tokens, breakpoints, and grid rules arrive documented and versioned.
