Capabilities

Three functions. No decoration.

grid_on

Twelve columns

Every page is composed on the same twelve-column grid. Elements align by default, across templates and teams.

format_line_spacing

One baseline

An 8px baseline governs all vertical spacing. Headlines, body text, and images share a single rhythm.

publish

Direct export

Finished layouts export to print-ready PDF and responsive HTML. No manual rework between formats.

Process

How it works

01

Define the grid

Set columns, gutters, and margins once. The grid becomes the shared reference for every page in the publication.

02

Place the content

Drop text and photography into grid cells. Alignment and spacing are enforced automatically as you work.

03

Publish the page

Export to PDF or HTML in one step. The output matches the layout exactly, at every screen size.
