Frequently asked questions

Short answers to the questions we hear most.

Does Primerline work with GitLab and Bitbucket?
Yes. GitHub has the deepest integration, and GitLab and Bitbucket connect through our standard Git adapter with full queue and policy support.
How does the merge queue keep main green?
Each queued pull request is rebased onto the latest main plus everything ahead of it, then retested. Only combinations that pass are merged.
Can I try the Team plan before paying?
Every workspace gets a 14-day Team trial with no credit card. After the trial you keep the free Starter plan unless you upgrade.
Is my source code stored on your servers?
No. Primerline reads metadata and diffs through the provider API and never clones your repository. Enterprise customers can run fully self-hosted.
What happens when a queued merge fails?
The failing pull request is removed from the queue, the author is notified with the failing check output, and the rest of the queue continues unaffected.
