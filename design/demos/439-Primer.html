Frequently asked questions

Short answers to the questions teams ask before migrating.

Does Forgebase replace our CI provider?
No. Forgebase sits on top of your existing CI. It reads check results from GitHub Actions, GitLab CI, Buildkite, or CircleCI and presents them inside the review.
How does the merge queue handle conflicts?
Each entry is rebased onto the latest main and retested before merging. If a rebase conflicts, the author is notified with the conflicting files and the queue continues with the next entry.
Can we keep our existing branch protection rules?
Yes. Rules are imported on install and stay in sync. You can manage them in Forgebase or in your Git host; both views show the same source of truth.
Is there a self-hosted option?
Enterprise customers can run Forgebase runners inside their own network. The control plane stays hosted by us, and no source code leaves your infrastructure.
What does the free tier include?
Starter covers unlimited public repositories with the full review experience. Private repositories, merge queues, and stacked PRs are part of the Team tier.
