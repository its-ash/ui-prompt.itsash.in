FAQ

Is the aurora animation heavy on GPU?
No. The animation uses lightweight CSS gradients and a minimal particle canvas that pauses when reduced motion is requested.
Can I use my own colour palette?
Yes. Edit the CSS variables in :root to replace the aurora colours while retaining the same structure.
Is the theme toggle accessible?
Absolutely. The button uses aria‑pressed, aria‑label, and persists the choice via localStorage.
