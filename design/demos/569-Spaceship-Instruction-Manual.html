06. TROUBLESHOOTING

Frequently Logged Issues

Answers from the manual, in plain language.

Q-01What happens if a pre-flight check fails?expand_more

The launch aborts before any traffic shifts. You receive a full diagnostic report identifying the failed gauge, and production stays on the last verified build.

Q-02Can I roll back without downtime?expand_more

Yes. Re-entry rollback is a traffic switch, not a redeploy. The previous vessel stays warm in orbit, so reverting takes seconds with zero dropped requests.

Q-03Which Git providers are supported?expand_more

GitHub, GitLab, and Bitbucket dock natively. Any other provider with a standard Git remote can connect through the manual docking procedure in the appendix.
