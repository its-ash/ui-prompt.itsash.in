# Coding AI Prompt — Tedy-Themed Landing Page

You are an expert front-end developer. Build a complete, production-grade landing page implementing the **Tedy** visual theme described below. The page must be responsive, accessible, and ship as separate `index.html`, `style.css`, and `script.js` files. Use a single consistent class-naming convention (BEM recommended). Do not write inline `style="..."` attributes. All styling lives in `style.css`. Use Tailwind CSS utilities mapped to CSS variables where helpful, but keep all design tokens in `:root` CSS variables.

## 1. Theme & Tokens

Implement the following design tokens as CSS variables in `:root`. Light mode is structural; dark mode must still be defined under `@media (prefers-color-scheme: dark)` and/or a `.dark` class, switching background/text variables seamlessly. Persist user theme choice via `localStorage`, falling back to `prefers-color-scheme` on first visit, with a visible toggle carrying correct `aria-pressed`/`aria-label`.

Also expose the standard semantic tokens: `--primary`, `--secondary`, `--bg-primary`, `--bg-secondary`, `--text-primary`, `--text-secondary`, `--text-success`, `--text-error`, `--border-default`, `--border-error`, `--border-success`. Map `--primary` to raspberry pulse, `--bg-primary` to pure white, `--text-primary` to ink black. Enforce contrast pairing: light backgrounds pair with dark text, dark backgrounds pair with light text, in every theme.

### Typography
Use Google Fonts. Bind `--font-base` to **Inter** (accessibility substitute for Montreal Neue). Load weights 400 and 500. Apply OpenType feature `"ss01" on` where supported. Georgia is accent-only (decorative serif, weight 700, 80px); load via system stack or Google Fonts as Source Serif Pro substitute.

Type scale tokens:
```

--text-body-sm: 16px / 1.5 / -0.08px;
--text-subheading: 23px / 1.38 / -0.12px;
--text-heading-sm: 28px / 1.05 / -0.56px;

--text-display-xl: 104px / 0.90 / -6.76px;
```
Display sizes (56px+) must use line-height under 1.0 and tracking between -0.025em and -0.065em. Body sizes (14–23px) use line-height 1.38–1.50 with minimal tracking.

### Spacing, Radius, Shadows, Elevation
Base unit 4px. Spacing scale: 8,12,16,20,24,28,32,36,40,48,56,72,80,84,96,112 (px) as `--spacing-*`. Radius: cards 32px, badges 32px, images 24px, buttons 999px, nav-pills 999px, small-cards 16px, feature-cards 20px. Shadows: `--shadow-xl`, `--shadow-subtle`, `--shadow-xl-2` (raspberry tinted), `--shadow-subtle-2`. Elevation tokens: `--z-dropdown`, `--z-modal`, `--z-toast`. Transitions: `--transition-fast`, `--transition-normal`, `--ease-standard`.

### Layout
Page max-width 1200px centered. Section gap 80px. Card padding 24px. Element gap 16px. Mobile-first flexbox; default `align-items: center` on every flex container unless justified. No horizontal scroll.

## 2. Component Requirements

Build and style all states via CSS classes (no inline styles):

**Buttons:** Default (flex, align-items center, justify-content center, gap 0.5rem, min 44x44px), Hover (brightness/shadow, cursor pointer), Focus (distinct ring via CSS vars), Active (transform scale 0.97), Loading (disabled, spinner/animated Google Icon, no dimension change), Disabled (opacity 0.5, greyscale, cursor not-allowed), Success/Error (temporary feedback via success/error tokens). Variants: Primary CTA (raspberry fill, white text, 999px radius, 14px 24px padding, 16px weight 500, raspberry shadow), Ghost (white fill, ink black text, 1px silver border, 999px radius), Auth (carbon fill, white text, 999px radius). Buttons use Google Material Symbols for any icons.

**Cards:** Default (flex layout, subtle borders/elevation via vars), Hover (elevation/shadow shift or translateY(-2px)), Focus-within (border highlight), Loading skeleton (shimmer), Empty state (icon + guidance text). Variants: Hero card (lavender fill, 32px radius, 40-48px padding), Pastel feature card (white inner on colored bg, 16-20px radius, 24px padding), Floating product mockup (white, 32-48px radius, dramatic dark shadow stack), Testimonial card (lavender, 32-44px radius, split layout with portrait breaking right edge), Stat highlight card, Category selector card.

**Forms/Inputs:** States Empty, Focused, Filled, Valid, Invalid, Disabled, Read-only. Flex container wrapping label, input, error feedback.

**Modal/Popup:** Opening, Open, Loading, Success/Error, Closing (CSS transitions). Centered flex, backdrop overlay, Google Icon close button, focus trapping, close via Esc/overlay.

**Navigation Bar:** White bg, full-width, 18px vertical padding, 1200px max-width centered. Logo left, nav links center (text-only with dropdown chevrons), utility right: language pill (EN/ON) white outlined pill, primary CTA, auth button. Nav items 16px weight 500 ink black.

**Section Divider:** No hard divider; sections separated by switching pastel surface color and 80px vertical gap.

## 4. UX & Accessibility

- Responsive by default, fluid sizing, no horizontal overflow.
- Smooth CSS transitions on all state changes, respecting `prefers-reduced-motion`.
- Sufficient contrast in light and dark modes. Never rely solely on color for state. Semantic HTML5, correct ARIA roles/labels, logical focus order, full keyboard operability, `aria-live` for dynamic feedback.
- Mandatory visual feedback on every interaction.
- Destructive actions visually distinct in both themes.
- Icons via Google Material Symbols only; no inline SVGs or local icon files.
- No lorem-ipsum-only where real copy is supplied; here invent fictional copy.

## 5. Deliverables

- `index.html`, `style.css`, `script.js` (single deferred entry-point reference in HTML).
- BEM naming convention throughout.
- No placeholders beyond genuinely unspecified content.

## 6. Style Rules (Do/Don't)

Do: headlines 56px+ with lh under 1.0 and tracking -0.025em to -0.065em; raspberry pulse only for primary CTA fills and its shadow; 32px radius on cards/images/badges, 999px on buttons/pills; body 17px lh 1.43 tracking -0.005em; pastel washes behind white cards; 1200px max-width, 80px section gaps; weight 500 nav/buttons/labels, 400 body; colored radial glow on hero/key areas.

Don't: no second saturated color; no display tracking on body; no sharp 0-4px radii; no raspberry shadow on non-CTA; no dark surfaces except auth button/intentional dark cards; no display lh above 1.05; no new fonts; no borders where color contrast works; no display sizes below 56px for true headlines.

Output only the three files' contents as a single cohesive deliverable. No preamble.
