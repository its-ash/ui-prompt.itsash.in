## 1. Project Architecture

- Deliver three separate files: `index.html`, `style.css`, `script.js`. No inline `<script>` blocks beyond a single deferred entry-point reference. No inline `style="..."` attributes anywhere in the HTML.
- Use Tailwind CSS (via CDN) plus a dedicated `style.css` for all custom design tokens and component styles. All utility classes must map back to CSS variables or generic reusable class names (`.btn`, `.card`, `.input-group`).
- Enforce one consistent class-naming convention (BEM) across the entire deliverable — never mix conventions.
- Keep HTML clean, semantic, and agnostic of visual styling so that changing the look requires modifying only the CSS file.

Map these to the standard tokens: `--primary: var(--color-honey-yellow)`, `--secondary: var(--color-powder-blue)`, `--bg-primary: var(--color-ivory-page)`, `--bg-secondary: var(--color-sandstone)`, `--text-primary: var(--color-obsidian)`, `--text-secondary: var(--color-graphite)`, `--text-success: #2e7d32`, `--text-error: #c62828`, `--border-default: var(--color-pebble-border)`, `--border-error: var(--color-text-error)`, `--border-success: var(--color-text-success)`.

**Contrast pairing:** light backgrounds pair with dark text; dark backgrounds (footer) pair with light text. Enforce this for every theme.

**Light mode background:** use `#fffcf2` (ivory), never pure white. Where near-white is needed, use `#fefefe`.

**Border radius & shadows:** `--radius-sm: 0px`, `--radius-md: 0px`, `--radius-lg: 0px`. No drop shadows — `--shadow-sm: none`, `--shadow-md: none`. Elevation is tonal only.

**Spacing & transitions:** `--spacing-gap: 16px`, `--transition-fast: 150ms ease`, `--transition-normal: 250ms ease`, `--ease-standard: cubic-bezier(0.4, 0, 0.2, 1)`. Spacing scale: 8, 16, 24, 32, 40, 48, 64, 80, 96px.

**Elevation/stacking:** `--z-dropdown: 100`, `--z-modal: 200`, `--z-toast: 300`.

**Typography:** `--font-base: 'Instrument Sans', sans-serif` (weights 400, 500, 600). `--font-mono: 'Geist Mono', monospace` (weights 300, 400). Load both via Google Fonts `<link>` tags in `<head>`. Geist Mono is used for all nav links, button labels, badges, and tags — uppercase with wide positive tracking.

**Type scale:** caption 12px/1.5/0.54px; body-sm 14px/1.5/-0.09px; body 16px/1.71/-0.14px; subheading 20px/1.35/-0.18px; heading-sm 26px/1.2/-0.52px; heading 32px/1.15/-0.64px; heading-lg 44px/1.1/-0.88px; heading-xl 56px/1.05/-1.12px; display 80px/0.92/-2.32px; display-lg 96px/0.75/-3.17px.

**Icons:** Use Google Material Symbols/Icons via `<link>`. Never use raw inline SVGs or local icon files.

## 3. Mandatory Dark Mode

- Provide dark mode tokens under `@media (prefers-color-scheme: dark)` and a `.dark` class selector.
- In dark mode, invert the canvas: background becomes `#141414` (obsidian), text becomes `#fffcf2` (ivory), borders become `#393737` (smoke), accent honey yellow and powder blue remain but adjust contrast.
- Theme switching must persist via `localStorage`, falling back to `prefers-color-scheme` on first visit.
- Include a visible toggle control with correct `aria-pressed` and `aria-label` state.

## 4. Layout Standards

- Use Flexbox (`display: flex`) for all layout structures. Every flex container must default to `align-items: center` unless explicitly justified otherwise.
- Mobile-first responsive design. Convert rows to columns on smaller viewports. Prevent horizontal scrolling. Max container width 1200px centered.
- Section rhythm: 64–80px vertical gaps. No visible dividers between bands.

## 6. Core UX Rules

- Responsive by default, fluid sizing, no horizontal overflow.
- CSS transitions on all state changes (`transition: var(--transition-normal)`), respecting `prefers-reduced-motion`.

- Mandatory visual feedback on every click, hover, or submission.
- Destructive actions visually distinct in both themes.
- Minimum touch target 44x44px for buttons.
