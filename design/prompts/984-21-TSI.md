# Coding AI Prompt — 21 TSI Editorial Landing Page

## 1. Project Overview & Core Architecture

Build a complete, single-page landing page for a fictional brand (invent a name, product, and copy — never use "21 TSI" or any real brand name, logo, trademark, or product name). The aesthetic is **dark-mode editorial luxury**: austere monochrome UI (white type on black canvas, hairline rules) with full-bleed crimson photography carrying all emotional weight. The interface dissolves into atmosphere.

**File Structure (mandatory):**
- `index.html` — semantic markup only
- `style.css` — all styling, zero inline CSS
- `script.js` — deferred entry point only

**Naming Convention:** BEM throughout. Never mix conventions.

**CSS-First Architecture:** All styling strictly inside `style.css`. No `style="..."` attributes. Class/ID selectors only. HTML must remain clean, semantic, and agnostic of visual styling.

**Light Mode Background Rule:** Where a near-white surface is needed, use `#fefefe`, never `#ffffff` for backgrounds. (UI strokes remain `#ffffff`.)

## 3. Typography & Icons

- **Font:** Google Fonts import for Inter (substitute for Saans). Bind to `--font-base`. Weights: 300, 400, 500, 700 (map to 300/380/570/790 ladder). Use Inter's tight tracking.
- **Icons:** Google Material Symbols. No raw inline SVGs or local icon files.
- **Tracking rules:**
  - Uppercase UI labels (12–20px): `+0.05em` letter-spacing (0.6px at 12px).
  - Display sizes (47px+): `-0.025em` letter-spacing.
- **Line heights:** 1.0–1.15 for display, 1.30–1.43 for body.
- **Scale philosophy:** Non-linear. Below 20px cluster tightly (12/14/16/18/20). Above 47px explode (47/79/106/130/136/245). No intermediate sizes (no 30px, no 60px). The gap between 20px and 47px is intentional silence.

## 4. Layout & Flexbox Standards

- All layout via Flexbox (`display: flex`). Default `align-items: center` on every flex container unless explicitly justified.
- Mobile-first responsive. Convert rows to columns on small viewports. No horizontal scrolling.
- **Full-bleed throughout:** No max-width content container. No card grids. No multi-column body text. Layout is a vertical stack of photographic viewports with hairline-separated content strips.
- Section rhythm: 30–60px gaps between sections. Asymmetric content: figures off-center, text left-aligned with 38px+ left margin, right side left empty.

## 5. Component Specifications

### 5.1 Top Nav Bar
- Single 1px white hairline edge-to-edge across top.
- Items float below in Saans/Inter 12px, weight 380 (400), uppercase, letter-spacing 0.6px, white.
- Logo wordmark left: 'XX|YYY' (fictional) with 1px vertical bar separator (~12px tall).
- Nav links distributed across bar with ~38px horizontal gaps.
- Utility cluster right: CONTACT, language toggle, sound toggle.
- No background fill, no border below — just the hairline above.
- Mobile: collapse to hamburger (Material Symbol), full-screen overlay menu.

### 5.2 Ghost Pill Button
- 70px border-radius, 1px white border, transparent fill, padding 10px 20px.
- Label: 12px, weight 380, uppercase, letter-spacing 0.6px, white.
- Leading 4px white circle as active/online indicator (before CONTACT).
- States: hover (opacity shift / subtle brightness), focus (distinct ring via CSS vars), active (scale 0.97), loading (CSS spinner, no dimension change), disabled (opacity 0.5, greyscale, not-allowed), success/error (temporary feedback via --text-success/--text-error).
- Minimum touch target 44x44px.

### 5.3 Nav Link
- Inline text only. No background, no border. 12px, weight 380, uppercase, letter-spacing 0.6px, white.
- Hover: subtle opacity shift only.

### 5.4 Full-Bleed Editorial Hero
- 100vw wide, ~90vh tall. Photograph as background (use a placeholder image URL with crimson/dramatic mood).
- No overlay, no scrim, no headline on top of image.
- Single human figure off-center (rule-of-thirds left), profile or three-quarter, motion implied.
- Nav sits above as 60–80px strip.

### 5.5 Display Headline
- 79–245px, weight 300 (light) for dramatic moments or 570 (500) for declarative. Line-height 1.0–1.14, letter-spacing -0.025em. White.
- Set above or below its own section of negative space — never on top of hero photograph.
- No shadow, no outline.

### 5.6 Circular Frame (594px radius)
- Square container, 594px border-radius → full circle. For portrait crops or signature graphic elements.

### 5.7 Body Card (8px radius)
- 8px border-radius, 1px #4d4d4d border, transparent or #000000 fill, 20px padding.
- Body text: 16px, weight 380, line-height 1.43, letter-spacing 0.8px, white.
- Used sparingly (forms, modals, grouped content).
- States if interactive: hover (elevation/shadow shift or translateY(-2px)), focus-within (border highlight), loading skeleton (shimmer), empty state (Google Icon + guidance text).

### 5.8 Form & Input (if used in CTA/Footer)
- States: empty, focused (outline ring), filled, valid (success border/icon), invalid (error border, red text, error icon), disabled, read-only.
- Flex container wrapping label, input, error feedback container.

### 5.9 Modal (if used)
- States: opening, open, loading, success/error, closing (CSS transitions).
- Centered flex container, backdrop overlay, Material Symbol close button, Esc/overlay close, focus trapping.

## 6. Section Requirements (Landing Page)

Build these sections in order:

1. **Hero** — Full-bleed editorial hero image (100vw, ~90vh). Nav above. No headline on image. Optional small uppercase label below image in its own breathing space.
2. **Features** — 3 cards (8px radius, 1px #4d4d4d border). Each: Material Symbol icon (or primitive), title (20px or 47px), body (16px). Flex layout, mobile stacks.
3. **How It Works** — 3 steps. Numbered (display size optional), title, description. Asymmetric left-aligned with 38px+ margin.
4. **Testimonials** — Quote text (large, 47px+ or 20px), attribution. No card chrome — just type on black.
5. **Pricing** — 3 tiers. Ghost pill buttons for CTAs. Highlighted tier uses white border emphasis (no fill change). Body card styling.
6. **FAQ** — Accordion. Question (uppercase 12–20px), answer (16px). Expand/collapse via CSS + minimal JS. `aria-expanded`, `aria-controls`.
7. **Final CTA** — Display headline (130px+), ghost pill button. Own section of negative space. Never on top of hero.
8. **Footer** — Secondary links, small uppercase labels (12px), 1px hairline top border. No heavy chrome.

## 7. Core UX & Micro-Interaction Rules (Global)

- **Responsive by default:** Fluid sizing, breakpoints, no horizontal overflow.
- **Smooth animations:** CSS transitions on all state changes (`transition: var(--transition-normal)`). Respect `prefers-reduced-motion`.
- **Accessibility:** Sufficient contrast in both modes. Never rely solely on color for state. Semantic HTML5, correct ARIA roles/labels, logical DOM/focus order, full keyboard operability, `aria-live` regions for dynamic feedback.
- **Mandatory visual feedback:** Every click, hover, submission triggers visible state change.
- **Destructive actions:** `.btn-danger` visually distinct in both themes.
- **No drop shadows, glows, or elevation effects.** Flat only. Depth comes from photography.
- **No solid red CSS background.** Crimson is always a photograph, never a fill.
- **No filled buttons with chromatic background.** All interactive controls are ghost/outlined with 1px white border.
- **No body text on top of editorial photography.** Give text its own background or breathing space.
- **No second typeface or icon font.** Every glyph from Inter or primitive shapes.
- **No max-width content container.** Full-bleed by philosophy.
- **No display sizes below 47px or above 245px.**
