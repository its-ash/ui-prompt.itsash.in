# UI/UX Specification Prompt — Osmo-Themed Landing Page

## 1. Project Overview

Build a complete, responsive landing page for a **fictional** developer-tools brand. Do NOT use the real brand name "Osmo," its logo, trademarks, or product names anywhere in the page. Invent a fictional brand name, product name, and all copy. The visual system must reuse the Osmo style reference below exactly, adapted to the fictional brand.

**Deliverables:** Separate `index.html`, `style.css`, and `script.js` files. No inline `<script>` blocks beyond a single deferred entry-point reference. No inline `style="..."` attributes anywhere in the HTML.

## 2. Theme & Visual System

### 2.1 Color Tokens (CSS Variables in `:root`)

Define all color tokens as CSS variables. Light mode is the default; dark mode must be supported via `@media (prefers-color-scheme: dark)` and a `.dark` class selector, with `localStorage` persistence and a visible toggle with correct `aria-pressed`/`aria-label`.

```css
:root {
  --color-concrete: #f4f4f4;
  --color-ash-gray: #eaeaea;
  --color-bone: #e1e1e1;
  --color-smoke: #b8b8b8;
  --color-graphite: #4f4c4c;
  --color-steel: #7a7a7a;
  --color-charcoal: #312e2e;
  --color-ink: #201d1d;
  --color-obsidian: #151313;
  --color-volt: #a1ff62;
  --color-ultraviolet: #6840ff;
  --color-vermillion: #f84131;
}
```

Contrast pairing: light backgrounds pair with dark text (`--color-ink` or `--color-charcoal`); dark backgrounds (`--color-obsidian`) pair with light text (`--color-concrete`). Vermillion is used only as annotation text in Brisa Pro style — never as fill, border, or background.

### 2.2 Typography

Use Google Fonts. Bind to `--font-base`. Substitute Haffer VF with **Inter** (weights 400, 500, 700). Substitute Haffer XH with **Inter Display** or a compressed geometric sans (weight 400). Substitute Haffer Mono with **JetBrains Mono** (weight 400). Substitute Brisa Pro with **Caveat** (weight 400). Include `<link>` tags in `<head>`.

Type scale tokens (use as `--text-*`):

| Role | Size | Line Height | Letter Spacing |
|------|------|-------------|----------------|
| mono-label | 11px | 1 | — |
| caption | 13px | 1.54 | -0.09px |
| body-sm | 16px | 1.3 | -0.16px |
| body | 19px | 1.25 | -0.38px |
| annotation | 25px | 0.8 | — |
| subheading | 48px | 1.05 | -1.44px |
| heading-sm | 64px | 1 | -1.92px |
| heading | 80px | 0.95 | -4px |
| heading-lg | 112px | 0.9 | -5.6px |
| display | 150px | 0.85 | -9px |

Display sizes (40px+) MUST use line-heights below 1.0 and negative tracking. Never normalize to 1.0+.

### 2.3 Spacing & Shape Tokens

```css
:root {
  --spacing-4: 4px; --spacing-5: 5px; --spacing-6: 6px; --spacing-7: 7px;
  --spacing-8: 8px; --spacing-10: 10px; --spacing-12: 12px; --spacing-16: 16px;
  --spacing-18: 18px; --spacing-20: 20px; --spacing-24: 24px; --spacing-30: 30px;
  --spacing-40: 40px; --spacing-60: 60px; --spacing-64: 64px; --spacing-80: 80px;
  --radius-sm: 2px; --radius-md: 5px; --radius-lg: 1600px;
  --radius-pill: 48px; --radius-icon: 160px;
  --shadow-sm: none; --shadow-md: none;
  --transition-fast: 150ms ease; --transition-normal: 250ms ease;
  --ease-standard: cubic-bezier(0.4, 0, 0.2, 1);
  --z-dropdown: 10; --z-modal: 50; --z-toast: 100;
  --font-base: 'Inter', sans-serif;
}
```

No gradients, drop shadows, or glassmorphism. Flat concrete aesthetic.

### 2.4 Radius Philosophy

SHARP (2px, 5px) for content tiles, cards, inputs, images. EXTREME (160px, 1600px) for buttons, badges, tags, pills. Never use mid-range radii (8px, 12px).

## 3. Layout & Architecture

- Page max-width: 1200px, centered content column.
- Full-width concrete canvas (`--color-concrete` background).
- Section gap: 64px.
- Card padding: 16px. Element gap: 8px.
- Mobile-first, flexbox-based. Default `align-items: center` on all flex containers unless justified.
- No horizontal scrolling. Responsive breakpoints: convert rows to columns on small viewports.
- Floating pill nav bar at top (not full-bleed header).
- Respect `prefers-reduced-motion`.

## 4. Component Requirements

### 4.1 Floating Navigation Bar
- Concrete background, 1px Ink border, 1600px radius, 8px vertical padding. No shadow.
- Left: "Menu" trigger. Center: wordmark. Right: Ghost text link "Login" + Volt CTA "Join".
- Flex layout, `align-items: center`.

### 4.2 Buttons
- **Volt CTA:** Volt fill, Ink text, 16px Inter weight 700, 8px 20px padding, 1600px radius. Min touch target 44x44px.
- **Ink Pill:** Obsidian fill, Concrete text, same padding/radius.
- **Ghost Text Link:** Ink text, 14–16px, no underline default; hover slides in 2px Ink bottom border. Often 48px-radius pill.
- All states: hover (brightness/shadow shift, cursor pointer), focus (distinct ring via CSS vars), active (scale 0.97), loading (CSS spinner, no dimension distortion), disabled (opacity 0.5, grayscale, not-allowed), success/error (via `--text-success`/`--text-error`).

### 4.3 Product Resource Card
- Obsidian background, 5px radius, 1px Charcoal border, 16px padding.
- Title: Concrete, 16px Inter. Sub-label: Smoke, 11px JetBrains Mono.
- Tilted -3° rotation in fan layout.

### 4.4 Featured Testimonial Card
- Ultraviolet background, 5px radius, 32px padding.
- Headline: Concrete, 48px compressed display, lh 1.05, ls -1.44px.
- Body quote: Concrete, 16px Inter.
- Avatar circle (80px) + name (16px Inter) + role badge (Volt pill).

### 4.5 Volt Badge
- Volt fill, 2px or 1600px radius, Ink text, JetBrains Mono 11px or Inter 12px weight 700, 3px 8px padding.

### 4.6 Input Field
- Ash Gray background, 1px Charcoal border, 5px radius, 10px 12px padding.
- Placeholder: Steel, 14px Inter. Focus: 2px Volt outer ring.

### 4.7 Annotation Callout
- Vermillion text, Caveat 25px, lh 0.80, with hand-drawn arrow. No background/border.

### 4.8 Modal/Popup
- Opening/Open/Loading/Success/Error/Closing states animated via CSS transitions.
- Centered flex container, backdrop overlay, Google Icon close button, Esc/overlay close, focus trapping.

### 4.9 Forms
- States: empty, focused, filled, valid, invalid, disabled, read-only.
- Flex container wrapping label, input, error feedback.

## 6. Core UX Rules

- Semantic HTML5, correct ARIA roles/labels, logical DOM/focus order, full keyboard operability.
- `aria-live` regions for dynamic feedback (form errors, toasts, loading).
- Never rely solely on color for state. Sufficient contrast in both modes.
- Smooth CSS transitions on all state changes, respecting `prefers-reduced-motion`.
- Mandatory visual feedback on every click/hover/submission.
- Destructive actions visually distinct in both themes.
- Class naming: use BEM consistently. No mixing conventions.

## 7. Content Rules

- Invent a fictional brand name, product name, and all copy. Never use "Osmo" or its trademarks.
- No lorem-ipsum-only submissions where real copy is expected; placeholders only where genuinely unspecified.
- Write all user-facing copy in English.

## 8. Dark Mode

- Define dark tokens under `@media (prefers-color-scheme: dark)` and `.dark` class.
- Concrete canvas → Obsidian; Ink text → Concrete; etc. Maintain contrast pairing.
- Theme toggle with `localStorage` persistence, falling back to `prefers-color-scheme` on first visit.

- `index.html`, `style.css`, `script.js` — separate files.
- No inline CSS. Class/ID selectors only.
- Google Fonts via `<link>` or `@import`.
